# L0124: Declaração de campo ou item

"É" e "começa" declaram um nome novo. Um campo de registro ("o saldo da carteira") ou um item de lista ("a primeira das notas") já existe dentro do valor que o contém, e não se declara de novo. Para trocar o valor dele, use "vira", com o valor de fora declarado com "começa".

## Errado

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    A primeira das notas é 10.
    Escrevo as notas.
```

## Certo

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    A primeira das notas vira 10.
    Escrevo as notas.
```
