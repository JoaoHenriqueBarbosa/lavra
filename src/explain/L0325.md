# L0325: "Devolvo" com valor em função que não devolve

O cabeçalho é o contrato da função: sem ", devolvendo um ...", ela não entrega valor a quem chama, e quem chama não espera nenhum. Um "Devolvo" com valor nesse corpo quebraria o contrato; o mesmo vale para "Para começar", que nunca devolve valor. Se a função deve entregar o valor, acrescente ", devolvendo um ..." ao cabeçalho; se não, use "Devolvo." sem valor.

## Errado

```lavra
Para saudar o nome, sendo o nome um texto:
    Devolvo "Olá, " seguido do nome.

Para começar:
    Saúdo "Ana".
```

## Certo

```lavra
Para saudar o nome, sendo o nome um texto, devolvendo um texto:
    Devolvo "Olá, " seguido do nome.

Para começar:
    Saúdo "Ana" e escrevo o resultado.
```
