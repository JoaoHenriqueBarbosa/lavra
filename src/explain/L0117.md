# L0117: Comparação com a preposição errada

Cada comparação rege uma preposição fixa, como um verbo: "maior que", "menor que", "igual a", "diferente de". Na Lavra a regência é parte da assinatura que o compilador confere, e cada comparação tem uma forma só: nem "maior do que", que o português aceita, nem "igual com". Use a preposição que a comparação rege.

## Errado

```lavra
Para começar:
    O saldo é 120.
    Se o saldo for maior do que 100:
        Escrevo "acima do teto".
```

## Certo

```lavra
Para começar:
    O saldo é 120.
    Se o saldo for maior que 100:
        Escrevo "acima do teto".
```
