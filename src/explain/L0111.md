# L0111: Nome depois de "houver" com artigo ou faltando

"Se houver apelido" pergunta se um valor "talvez" está presente, e o nome vem logo depois de "houver", sem artigo, como no português ("se houver troco", não "se houver o troco"). Dentro do bloco, o nome volta a levar artigo e dá o valor presente: "o apelido". Tire o artigo, ou ponha o nome que faltou.

## Errado

```lavra
Para começar:
    O apelido, talvez um texto, é "Bia".
    Se houver o apelido:
        Escrevo o apelido.
```

## Certo

```lavra
Para começar:
    O apelido, talvez um texto, é "Bia".
    Se houver apelido:
        Escrevo o apelido.
```
