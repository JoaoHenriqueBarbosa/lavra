# L0366: "Conforme" sobre valores sem "Senão"

Uma enumeração tem uma lista fechada de casos, e o compilador confere se todos foram tratados. Um inteiro, um caractere ou um texto podem ter qualquer valor: por mais casos que o "Conforme" liste, sempre pode chegar outro, e ele passaria sem ninguém o tratar. Por isso o "Conforme" sobre valores termina com "Senão". Só o lógico dispensa, quando "verdadeiro" e "falso" foram os dois tratados.

## Errado

```lavra
Para começar:
    O dia é 3.
    Conforme o dia:
        Sendo 1: escrevo "domingo".
        Sendo 2: escrevo "segunda".
```

## Certo

```lavra
Para começar:
    O dia é 3.
    Conforme o dia:
        Sendo 1: escrevo "domingo".
        Sendo 2: escrevo "segunda".
        Senão: escrevo "outro dia".
```
