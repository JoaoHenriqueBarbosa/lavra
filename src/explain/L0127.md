# L0127: Tipo sem artigo indefinido

O aposto de tipo é um substantivo com artigo indefinido, como no português: "o limite, um inteiro, é 100" diz que o limite é um inteiro. O artigo marca que ali vem um tipo, e não um nome, e concorda com ele ("um inteiro", "uma lista"). Escreva o tipo com "um" ou "uma".

## Errado

```lavra
Para começar:
    O limite, inteiro, é 100.
    Escrevo o limite.
```

## Certo

```lavra
Para começar:
    O limite, um inteiro, é 100.
    Escrevo o limite.
```
