# L0301: Função que pode terminar sem devolver

Uma função com ", devolvendo um ..." no cabeçalho promete um valor a quem chama, e a promessa vale para todo caminho que a execução pode seguir. O compilador não avalia as condições: o bloco de um "Se" sem "Senão" ou de um "Enquanto" pode não rodar, e o corpo chegaria ao fim sem valor nenhum para entregar. Termine o corpo com um "Devolvo ...", ou faça cada ramo de um "Se" com "Senão" devolver o seu valor.

## Errado

```lavra
Para classificar a nota, sendo a nota um inteiro, devolvendo um texto:
    Se a nota for pelo menos 6: devolvo "aprovado".

Para começar:
    Escrevo o resultado de classificar 8.
```

## Certo

```lavra
Para classificar a nota, sendo a nota um inteiro, devolvendo um texto:
    Se a nota for pelo menos 6: devolvo "aprovado".
    Devolvo "reprovado".

Para começar:
    Escrevo o resultado de classificar 8.
```
