# L0150: Predicado com "ir"

Um cabeçalho com sujeito antes do verbo define um predicado, que se chama como condição, no futuro do subjuntivo: "Se o elevador subir até 5:". O futuro do subjuntivo de "ir" é "for", a mesma forma de "ser", que a língua usa nas comparações ("Se o elevador for menor que 5"); com um predicado "ir", a condição "Se o elevador for até 5:" teria duas leituras. Por isso o predicado com "ir" não se define: escolha outro verbo, como "seguir", "chegar" ou "subir".

## Errado

```lavra
Para o elevador ir até o andar, sendo ambos inteiros, devolvendo um lógico:
    Devolvo o fato de o elevador ser menor que o andar.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para o elevador subir até o andar, sendo ambos inteiros, devolvendo um lógico:
    Devolvo o fato de o elevador ser menor que o andar.

Para começar:
    O elevador é 2.
    Se o elevador subir até 5: escrevo "sobe".
```
