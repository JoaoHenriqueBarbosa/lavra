# L0167: Particípio que não concorda com o tipo

Os particípios "emprestado" e "confiado" dizem como o parâmetro chega à função, e concordam com o tipo que vem logo antes deles, não com o nome do parâmetro. Em "sendo as notas uma lista de reais emprestada", o tipo é "uma lista", feminino singular, então o particípio é "emprestada", mesmo com "as notas" no plural; na tipagem de vários parâmetros o tipo vai no plural, e o particípio também ("a origem e o destino reais confiados"). Troque o particípio pela forma que concorda com o tipo.

## Errado

```lavra
Para somar as notas,
        sendo as notas uma lista de reais emprestadas, devolvendo um real:
    O total começa em 0,0.
    Para cada nota das notas: o total cresce a nota.
    Devolvo o total.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para somar as notas,
        sendo as notas uma lista de reais emprestada, devolvendo um real:
    O total começa em 0,0.
    Para cada nota das notas: o total cresce a nota.
    Devolvo o total.

Para começar:
    As provas são 7, 8,5 e 9.
    Escrevo o resultado de somar as provas.
```
