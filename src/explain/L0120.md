# L0120: Verbo na 3ª pessoa onde o programa age

Quando o programa age (escreve, lê, devolve, chama uma função), ele narra em 1ª pessoa: "Escrevo", "Leio", "Transfiro". A 3ª pessoa fica para os dados, que são sujeitos do que acontece com eles: "o saldo cresce", "a lista ganha". Um "Escreve" sem sujeito não diz quem escreve; ponha o verbo na 1ª pessoa.

## Errado

```lavra
Para começar:
    O nome é "Ana".
    Escreve "Olá, " seguido do nome.
```

## Certo

```lavra
Para começar:
    O nome é "Ana".
    Escrevo "Olá, " seguido do nome.
```
