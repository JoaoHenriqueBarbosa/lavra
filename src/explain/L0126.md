# L0126: "talvez talvez"

Um valor "talvez" está presente ou ausente, e há um jeito só de estar ausente: "nada". "talvez talvez um texto" pediria dois níveis de ausência, que a Lavra não distingue. Escreva "talvez" uma vez só.

## Errado

```lavra
Para começar:
    O apelido, talvez talvez um texto, começa em nada.
    O apelido vira "Bia".
    Se houver apelido: escrevo o apelido.
```

## Certo

```lavra
Para começar:
    O apelido, talvez um texto, começa em nada.
    O apelido vira "Bia".
    Se houver apelido: escrevo o apelido.
```
