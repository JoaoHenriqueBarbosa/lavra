# L0008: Hexadecimal sem dígitos

Um número hexadecimal é "0x" seguido de pelo menos um dígito de 0 a 9 ou de A a F, tudo junto: "0xFF", "0x1F". Sem dígitos colados ao prefixo, o "0x" não tem valor, e o léxico não adivinha que os dígitos vêm depois de um espaço. Escreva os dígitos logo depois do "x".

## Errado

```lavra
Para começar:
    A máscara é 0x FF.
    Escrevo a máscara.
```

## Certo

```lavra
Para começar:
    A máscara é 0xFF.
    Escrevo a máscara.
```
