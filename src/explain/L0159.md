# L0159: "salvo uma falha" malformado

Uma função que pode falhar se declara no fim do cabeçalho com a locução "salvo uma falha", sempre nessa forma: a língua não aceita sinônimo ("salvo um erro") nem a locução pela metade ("salvo falha"). É por ela que o compilador sabe que a função pode desistir, e então exige que cada chamada diga o que fazer com a falha (", ou 0", ", ou desisto"). Escreva "salvo uma falha".

## Errado

```lavra
Para dividir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro, salvo um erro:
    Se as pessoas forem menores que 1: desisto com "ninguém para dividir".
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de dividir 100 entre 4, ou 0.
```

## Certo

```lavra
Para dividir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro, salvo uma falha:
    Se as pessoas forem menores que 1: desisto com "ninguém para dividir".
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de dividir 100 entre 4, ou 0.
```
