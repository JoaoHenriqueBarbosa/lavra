# L0371: Tipo sem ordem onde se pede ordenável

"qualquer ordenável" no cabeçalho diz que a função compara os valores com "maior que" e "menor que", e por isso só vale para tipos que têm ordem: os números, o caractere e o texto. Um registro, uma lista ou um lógico não têm, e a chamada com um deles é recusada antes de rodar. Passe à função o que se compara (o saldo, e não a conta inteira).

## Errado

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para escolher entre o esquerdo e o direito, sendo ambos elementos quaisquer ordenáveis, devolvendo um elemento:
    Se o esquerdo for maior que o direito: devolvo o esquerdo.
    Devolvo o direito.

Para começar:
    A poupança é uma conta com o saldo 1.
    A reserva é uma conta com o saldo 2.
    Escrevo o resultado de escolher entre a poupança e a reserva.
```

## Certo

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para escolher entre o esquerdo e o direito, sendo ambos elementos quaisquer ordenáveis, devolvendo um elemento:
    Se o esquerdo for maior que o direito: devolvo o esquerdo.
    Devolvo o direito.

Para começar:
    A poupança é uma conta com o saldo 1.
    A reserva é uma conta com o saldo 2.
    Escrevo o resultado de escolher entre o saldo da poupança e o saldo da reserva.
```
