# L0202: Tipo definido duas vezes

Cada registro ou enumeração tem uma definição só, porque é pelo nome que o programa diz o tipo ("um produto") e constrói os valores ("um produto com o nome ..."). Uma segunda definição com o mesmo nome deixaria essas frases sem saber de qual tipo falam, e não acrescenta campos à primeira. Junte os campos numa definição só, ou dê outro nome ao segundo tipo.

## Errado

```lavra
Um produto é um registro de:
    o nome, um texto;
    o preço, um real.

Um produto é um registro de:
    o nome, um texto;
    o estoque, um inteiro.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Um produto é um registro de:
    o nome, um texto;
    o preço, um real;
    o estoque, um inteiro.

Para começar:
    O café é um produto com o nome "café", o preço 18,5 e o estoque 40.
    Escrevo o café.
```
