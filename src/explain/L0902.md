# L0902: Estouro no módulo

O módulo (o valor absoluto) de um inteiro com sinal nem sempre cabe no próprio tipo, porque a faixa tem um negativo a mais que positivos. Num inteiro de 8 bits, que vai de -128 a 127, o módulo de -128 seria 128, e o programa para em vez de devolver um número errado. Converta para um tipo maior antes de tirar o módulo: "o módulo de (a leitura como inteiro de 16 bits)".

## Errado

```lavra
Para começar:
    A leitura, um inteiro de 8 bits, é -128.
    Escrevo "distância do zero: " seguido do módulo da leitura.
```

## Certo

```lavra
Para começar:
    A leitura, um inteiro de 8 bits, é -128.
    Escrevo "distância do zero: " seguido do módulo de (a leitura como inteiro de 16 bits).
```
