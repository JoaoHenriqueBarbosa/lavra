# L0400: Valor usado depois de entregue

Texto, lista, registro, enumeração e "talvez" têm um dono só. Entregar o valor (declarar outro nome com ele, pô-lo depois de "vira" ou de "ganha", passá-lo a um parâmetro sem particípio, devolvê-lo) passa a posse adiante, e o nome antigo não se usa mais: assim a memória nunca tem dois donos, e ninguém lê um valor que o novo dono já mudou ou descartou. A conferência segue todos os caminhos do programa, então entregar dentro de um "Se" ou numa volta de laço também conta. Se a função só precisa ler, peça emprestado no cabeçalho ("sendo o aviso um texto emprestado"); se ela precisa de um valor só dela, entregue uma cópia ("Publico uma cópia do aviso.").

## Errado

```lavra
Para publicar o aviso, sendo o aviso um texto:
    Escrevo "no mural: " seguido do aviso.

Para começar:
    O aviso é "reunião às dez".
    Publico o aviso.
    Escrevo o aviso.
```

## Certo

```lavra
Para publicar o aviso, sendo o aviso um texto emprestado:
    Escrevo "no mural: " seguido do aviso.

Para começar:
```
