# L0302: Tipo que contém a si mesmo

Um registro guarda os campos dentro de si, então um campo do próprio tipo faria cada pessoa conter outra pessoa inteira, que contém outra, sem fim: o tipo teria tamanho infinito. Declarar o campo com "talvez" não quebra o ciclo, porque o valor presente também fica dentro; e uma enumeração com um caso que guarda a própria enumeração cai no mesmo erro. Guarde no campo o que identifica o outro, como o nome dele ou a posição dele numa lista.

## Errado

```lavra
Uma pessoa é um registro de:
    o nome, um texto;
    a mãe, uma pessoa.

Para começar:
    Escrevo "família".
```

## Certo

```lavra
Uma pessoa é um registro de:
    o nome, um texto;
    a mãe, um texto.

Para começar:
    A filha é uma pessoa com o nome "Ana" e a mãe "Rosa".
    Escrevo a mãe da filha.
```
