# L0302: Tipo que contém a si mesmo

Um registro guarda os campos dentro de si, então um campo do próprio tipo faria cada pessoa conter outra pessoa inteira, que contém outra, sem fim: o tipo teria tamanho infinito, e nenhum valor dele poderia ser escrito. O mesmo vale para a enumeração com um caso que guarda a própria enumeração. Duas coisas quebram o ciclo, porque guardam por fora: a lista ("os filhos, uma lista de pessoas", que é como se fazem árvores) e o "talvez" ("a mãe, talvez uma pessoa", que é como se faz uma corrente que acaba em "nada"). Ponha o campo numa lista ou num "talvez".

## Errado

```lavra
Uma pessoa é um registro de:
    o nome, um texto;
    a mãe, uma pessoa.

Para começar:
    Escrevo "família".
```

## Certo

```lavra
Uma pessoa é um registro de:
    o nome, um texto;
    a mãe, um texto.

Para começar:
    A filha é uma pessoa com o nome "Ana" e a mãe "Rosa".
    Escrevo a mãe da filha.
```
