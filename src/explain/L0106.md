# L0106: "Senão" sem "Se"

O "Senão" responde ao "Se" que está logo acima dele, no mesmo recuo e sem nenhuma oração no meio. Recuado para dentro do bloco, ou depois de outra oração, ele não tem a que condição responder. Alinhe o "Senão" com o "Se" a que ele pertence, logo depois do bloco do "Se".

## Errado

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for maior que 5:
        Escrevo "alto".
        Senão:
            Escrevo "baixo".
```

## Certo

```lavra
Para começar:
```
