# L0004: Caractere com mais de uma letra

Aspas simples guardam um caractere só: 's', '7', '\n'. Para uma palavra ou uma frase, use aspas duplas, que fazem um texto. A diferença é de tipo, e não só de grafia: o caractere é um valor de tamanho fixo, que se copia, e o texto tem tamanho variável e dono.

## Errado

```lavra
Para começar:
    A resposta é 'sim'.
    Escrevo a resposta.
```

## Certo

```lavra
Para começar:
    A resposta é "sim".
    Escrevo a resposta.
```
