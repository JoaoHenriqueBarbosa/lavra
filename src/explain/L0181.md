# L0181: "qualquer" que não concorda com o tipo

No cabeçalho, "qualquer" depois de um nome declara um tipo qualquer, e concorda em número com ele: "uma coisa qualquer", "uma lista de coisas quaisquer". O mesmo vale para "ordenável" e "ordenáveis". Troque a palavra pela forma que concorda.

## Errado

```lavra
Para mostrar as coisas, sendo as coisas uma lista de itens qualquer emprestada:
    Escrevo as coisas.

Para começar:
    As notas são 7, 8 e 9.
    Mostro as notas.
```

## Certo

```lavra
Para mostrar as coisas, sendo as coisas uma lista de itens quaisquer emprestada:
    Escrevo as coisas.

Para começar:
    As notas são 7, 8 e 9.
    Mostro as notas.
```
