# L0308: "Para cada" sem a coleção declarada

"Para cada nota:", sem dizer de onde vêm os itens, procura a coleção pelo plural do nome do item, "as notas", e esse nome precisa estar declarado. Quando a coleção tem outro nome, o plural não a encontra. Diga de onde vêm os itens: "Para cada nota das provas:".

## Errado

```lavra
Para começar:
    As provas são 7, 8 e 9.
    Para cada nota: escrevo a nota.
```

## Certo

```lavra
Para começar:
    As provas são 7, 8 e 9.
    Para cada nota das provas: escrevo a nota.
```
