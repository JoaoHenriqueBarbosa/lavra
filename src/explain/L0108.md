# L0108: Artigo depois de "cada"

"Cada" já é um determinante: ele escolhe os itens um a um, e por isso o nome vem logo depois dele, sem artigo, como no português ("para cada nota", não "para cada a nota"). Dentro do bloco, o item é um nome como outro qualquer e leva artigo: "a nota". Tire o artigo depois de "cada".

## Errado

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Para cada a nota:
        Escrevo a nota.
```

## Certo

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Para cada nota:
        Escrevo a nota.
```
