# L0340: Item de coleção de tipo ainda desconhecido

Uma lista que começa vazia, sem aposto, descobre o tipo dos itens pelo uso, e a análise lê o programa de cima para baixo. Aqui "a palavra" é usada como coleção ("a primeira da palavra") antes de qualquer oração dizer o que ela é; o "ganham" que revela que são textos só vem depois. Declare o tipo no aposto ("As palavras, uma lista de textos, começam vazias.") ou dê um item à lista antes de usar os itens dela.

## Errado

```lavra
Para começar:
    As palavras começam vazias.
    Para cada palavra das palavras:
        Escrevo a primeira da palavra.
    As palavras ganham "lavra".
```

## Certo

```lavra
Para começar:
    As palavras, uma lista de textos, começam vazias.
    Para cada palavra das palavras:
        Escrevo a primeira da palavra.
    As palavras ganham "lavra".
```
