# L0352: Construção sem todos os campos

Construir um registro exige dar valor a todos os campos depois de "com": na Lavra nada começa sem valor, nem campo de registro. Não existe valor padrão (zero, texto vazio) que o compilador invente em silêncio. Diga o valor de cada campo que falta; a mensagem lista quais são, e a regra vale também para os casos de enumeração com campos.

## Errado

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana".
    Escrevo a carteira.
```

## Certo

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 0,0.
    Escrevo a carteira.
```
