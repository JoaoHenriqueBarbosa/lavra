# L0374: Verbo que não está definido para o tipo

Um verbo definido para vários tipos vale só para eles: com "medir" definido para conta e para texto, medir um real não quer dizer nada. O mesmo erro aparece ao chamar uma função genérica que pede o verbo ("uma coisa qualquer que se mede") com um tipo que não o tem. Defina o verbo para esse tipo, com a mesma regência, ou passe um valor de um tipo que já o tem.

## Errado

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para começar:
    Escrevo o resultado de medir "lavra".
    Escrevo o resultado de medir 2,5.
```

## Certo

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para medir o real, sendo o real um real, devolvendo um inteiro:
    Devolvo o real como inteiro.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
    Escrevo o resultado de medir 2,5.
```
