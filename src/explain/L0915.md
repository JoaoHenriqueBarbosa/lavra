# L0915: Texto que não é número

"como" lê um texto como número: "42" como inteiro dá 42, e "3,5" como real dá 3,5, com a vírgula decimal e os espaços das pontas ignorados. Quando o texto não é um número do tipo pedido ("doze", "4x", um número grande demais para o tipo, ou com vírgula quando se pede inteiro), não há valor para devolver, e a Lavra interrompe o programa em vez de inventar um zero. Confira o texto antes de converter, ou leia direto no tipo ("Leio um inteiro.").

## Errado

```lavra
Para começar:
    A resposta é "doze".
    Escrevo (a resposta como inteiro) mais 1.
```

## Certo

```lavra
Para começar:
    A resposta é "12".
    Escrevo (a resposta como inteiro) mais 1.
```
