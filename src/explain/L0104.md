# L0104: "Repito" com "vez" no singular

O "Repito" conta em "vezes", sempre no plural, porque um laço existe para repetir. "Repito 1 vez" não repete nada: o bloco rodaria uma vez só, e para isso não é preciso laço. Escreva as orações direto, sem o "Repito"; para repetir de verdade, use "vezes" com a contagem ("Repito 3 vezes:").

## Errado

```lavra
Para começar:
    O total começa em 0.
    Repito 1 vez:
        O total cresce 5.
    Escrevo o total.
```

## Certo

```lavra
Para começar:
    O total começa em 0.
    O total cresce 5.
    Escrevo o total.
```
