# L0109: Caso de "Conforme" sem "Sendo"

Dentro de um "Conforme", cada caso começa com "Sendo" seguido do caso com artigo indefinido ("Sendo um vermelho:"), e os casos que sobram podem ir juntos num "Senão:". O "Sendo" é o que diz que a linha é um caso a comparar com o valor, e não uma oração solta dentro do bloco. Comece cada caso com "Sendo".

## Errado

```lavra
Um sinal é um destes:
    um vermelho;
    um amarelo;
    um verde.

Para começar:
    O farol é um verde.
    Conforme o farol:
        Um vermelho: escrevo "pare".
        Senão: escrevo "siga".
```

## Certo

```lavra
Um sinal é um destes:
    um vermelho;
    um amarelo;
    um verde.

Para começar:
    O farol é um verde.
    Conforme o farol:
        Sendo um vermelho: escrevo "pare".
        Senão: escrevo "siga".
```
