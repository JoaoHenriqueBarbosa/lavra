# L0305: Lista sem o tipo dos itens

Uma lista que começa vazia, sem aposto, deixa o tipo dos itens para depois: o compilador o descobre pelo primeiro item que entra nela ou sai dela. Se nada entra nem sai, o tipo nunca aparece, e o compilador não monta uma lista de itens sem tipo. Faça um item entrar, como abaixo, ou diga o tipo no aposto: "As compras, uma lista de textos, começam vazias."

## Errado

```lavra
Para começar:
    As compras começam vazias.
    Escrevo "itens: " seguido do tamanho das compras.
```

## Certo

```lavra
Para começar:
    As compras começam vazias.
    As compras ganham "pão".
    Escrevo "itens: " seguido do tamanho das compras.
```
