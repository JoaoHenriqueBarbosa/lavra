# L0161: Predicado que não devolve lógico

Um cabeçalho com sujeito antes do verbo ("Para a temperatura passar do limite") define um predicado, e o predicado se chama como condição: "Se a febre passar de 37,5:". Condição é verdadeira ou falsa, por isso o predicado devolve um lógico, e o cabeçalho precisa dizer ", devolvendo um lógico". Para calcular outro valor, use um verbo de ação, sem sujeito antes dele.

## Errado

```lavra
Para a temperatura passar do limite, sendo ambos reais, devolvendo um real:
    Devolvo a temperatura menos o limite.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para a temperatura passar do limite, sendo ambos reais, devolvendo um lógico:
    Devolvo o fato de a temperatura ser maior que o limite.

Para começar:
    A febre é 38,5.
    Se a febre passar de 37,5: escrevo "febre".
```
