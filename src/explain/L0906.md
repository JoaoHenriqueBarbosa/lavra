# L0906: Potência com expoente negativo

A potência de inteiros só aceita expoente de 0 para cima: 10 elevado a -1 é 0,1, que não é inteiro. Em vez de arredondar para 0 em silêncio, a Lavra interrompe o programa. Para expoente negativo, faça a conta com reais: "a potência de 10,0 e (n como real)".

## Errado

```lavra
Para começar:
    Para cada n de 2 até -2:
        Escrevo a potência de 10 e n.
```

## Certo

```lavra
Para começar:
    Para cada n de 2 até -2:
        Escrevo a potência de 10,0 e (n como real).
```
