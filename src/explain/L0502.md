# L0502: Função que nunca é chamada

Uma função definida que nenhuma oração chama é código morto: ela não roda, e o leitor perde tempo com ela. O aviso aparece só num programa sem erro, porque com erro a chamada pode estar justamente na oração que não se leu. Chame a função onde ela faz falta, ou apague a definição.

## Errado

```lavra
Para dobrar o valor, sendo o valor um inteiro, devolvendo um inteiro:
    Devolvo o valor vezes 2.

Para começar:
    Escrevo 21.
```

## Certo

```lavra
Para dobrar o valor, sendo o valor um inteiro, devolvendo um inteiro:
    Devolvo o valor vezes 2.

Para começar:
    Escrevo o resultado de dobrar 21.
```
