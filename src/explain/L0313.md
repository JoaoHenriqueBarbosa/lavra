# L0313: Nome igual a constante do programa

Uma constante do nível de fora vale no programa inteiro, dentro de todas as funções. Um nome local ou um parâmetro igual a ela esconderia a constante naquele trecho, e "a taxa" passaria a falar de coisas diferentes conforme o lugar; por isso a Lavra recusa. Dê outro nome ao valor local, ou, se o programa inteiro deve usar o valor novo, mude a constante.

## Errado

```lavra
A taxa é 0,05.

Para começar:
    O saldo é 1000,0.
    A taxa é o saldo vezes a taxa.
    Escrevo a taxa.
```

## Certo

```lavra
A taxa é 0,05.

Para começar:
    O saldo é 1000,0.
    O juro é o saldo vezes a taxa.
    Escrevo o juro.
```
