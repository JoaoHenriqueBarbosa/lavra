# L0182: Tipo qualquer fora de um cabeçalho

"uma coisa qualquer" declara um tipo que a função recebe de quem a chama, e isso só faz sentido no cabeçalho: é ali que cada chamada decide, pelos argumentos, que tipo é "coisa". No corpo da função o tipo já tem nome, e se cita sem "qualquer" ("As cópias, uma lista de coisas, começam vazias."). Fora de uma função genérica não há tipo qualquer: diga o tipo de verdade.

## Errado

```lavra
Para começar:
    O solto, uma coisa qualquer, é 1.
    Escrevo o solto.
```

## Certo

```lavra
Para começar:
    O solto, um inteiro, é 1.
    Escrevo o solto.
```
