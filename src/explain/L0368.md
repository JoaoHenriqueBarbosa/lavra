# L0368: Operação que o conjunto ou o mapa não tem

Lista, conjunto e mapa são coleções, mas cada uma tem o seu jeito. A lista tem posição: ganha no fim, perde "a primeira", "a última" ou "o item 2". O conjunto não tem posição: ganha e perde o próprio valor ("Os vistos perdem "Ana"."), e entre dois conjuntos há a união, a interseção e a diferença. O mapa não ganha item solto: cada chave entra com o valor dela ("O item "Ana" das idades vira 30."), sai pela chave ("As idades perdem "Ana".") e começa sempre vazio. Escreva a operação do jeito da coleção.

## Errado

```lavra
Para começar:
    Os vistos, um conjunto de textos, começam vazios.
    Os vistos ganham "Ana".
    Os vistos perdem a primeira.
    Escrevo os vistos.
```

## Certo

```lavra
Para começar:
    Os vistos, um conjunto de textos, começam vazios.
    Os vistos ganham "Ana".
    Os vistos perdem "Ana".
    Escrevo os vistos.
```
