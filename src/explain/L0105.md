# L0105: "Para cada" com nome igual no singular e no plural

"Para cada nota:" acha a coleção pelo plural do item: "as notas". Num nome igual no singular e no plural, como "lápis" ou "ônibus", o plural não diz de onde vêm os itens, e o compilador não adivinha. Diga a coleção com "de": "Para cada ônibus dos ônibus:"; dentro do bloco, o artigo separa o item ("o ônibus") da coleção ("os ônibus").

## Errado

```lavra
Para começar:
    Os ônibus são 101, 230 e 415.
    Para cada ônibus:
        Escrevo o ônibus.
```

## Certo

```lavra
Para começar:
    Os ônibus são 101, 230 e 415.
    Para cada ônibus dos ônibus:
        Escrevo o ônibus.
```
