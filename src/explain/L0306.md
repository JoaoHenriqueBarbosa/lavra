# L0306: "Repito" com contagem que não é inteira

"Repito N vezes" conta voltas inteiras, e um valor como 7,5 não diz o que fazer com a volta pela metade. A Lavra não arredonda nem trunca sem que o programa peça. Converta a contagem com "como inteiro", que descarta a parte fracionária, ou guarde-a num inteiro desde o começo.

## Errado

```lavra
Para começar:
    A média é 7,5.
    Repito a média vezes: escrevo "*" sem quebrar a linha.
```

## Certo

```lavra
Para começar:
    A média é 7,5.
    Repito a média como inteiro vezes: escrevo "*" sem quebrar a linha.
```
