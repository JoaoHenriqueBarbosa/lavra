# L0207: Caso sem artigo indefinido

Cada caso de uma enumeração se escreve com artigo indefinido: "um verde", "uma estrela". É o artigo que dá o gênero do caso, conferido depois em cada uso ("O semáforo começa em um vermelho.", "Se o semáforo for um verde:"), e é o mesmo jeito de apresentar um tipo ("um inteiro"). Ponha "um" ou "uma" antes de cada caso.

## Errado

```lavra
Um sinal é um destes:
    verde;
    amarelo;
    vermelho.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Um sinal é um destes:
    um verde;
    um amarelo;
    um vermelho.

Para começar:
    O semáforo começa em um vermelho.
    O semáforo vira um verde.
    Escrevo o semáforo.
```
