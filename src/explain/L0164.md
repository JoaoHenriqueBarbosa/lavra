# L0164: Tipagem que não concorda com o cabeçalho

Na tipagem, cada parâmetro é retomado com o mesmo artigo do cabeçalho, porque o artigo é parte do nome: é ele que diz o gênero e o número que o corpo da função confere. Num nome invariável, como "lápis", o artigo é a única marca do número: "os lápis" é uma coleção, "o lápis" é um só. Repita o nome exatamente como o cabeçalho o escreveu.

## Errado

```lavra
Para contar os lápis,
        sendo o lápis uma lista de textos emprestada, devolvendo um inteiro:
    Devolvo o tamanho dos lápis.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para contar os lápis,
        sendo os lápis uma lista de textos emprestada, devolvendo um inteiro:
    Devolvo o tamanho dos lápis.

Para começar:
    Os lápis são "azul" e "verde".
    Escrevo o resultado de contar os lápis.
```
