# L0006: Escape desconhecido

Dentro de um texto ou de um caractere, a barra invertida começa um escape, e a Lavra conhece seis: "\n" (quebra de linha), "\t" (tabulação), "\"" (aspas), "\'" (aspa simples), "\\" (a própria barra) e "\0". Qualquer outra letra depois da barra é erro, para que uma barra num caminho de arquivo não vire, em silêncio, outro caractere. Para escrever a barra, dobre-a.

## Errado

```lavra
Para começar:
    A pasta é "C:\arquivos".
    Escrevo a pasta.
```

## Certo

```lavra
Para começar:
    A pasta é "C:\\arquivos".
    Escrevo a pasta.
```
