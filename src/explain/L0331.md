# L0331: Caso perguntado de valor que não é enumeração

"Se o semáforo for um verde" pergunta qual caso de uma enumeração o valor é, e só enumeração tem casos. Um texto que diz "verde" não é o caso "um verde": são tipos diferentes, e a Lavra não troca um pelo outro por causa da grafia. Guarde no nome o próprio caso ("O semáforo é um verde.") ou, se o valor tem mesmo que ser texto, compare o texto com "igual a".

## Errado

```lavra
Um sinal é um destes:
    um verde;
    um vermelho.

Para começar:
    O semáforo é "verde".
    Se o semáforo for um verde: escrevo "siga".
```

## Certo

```lavra
Um sinal é um destes:
    um verde;
    um vermelho.

Para começar:
    O semáforo é um verde.
    Se o semáforo for um verde: escrevo "siga".
```
