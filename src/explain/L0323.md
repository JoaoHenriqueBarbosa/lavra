# L0323: Leitura de um tipo que não se lê

"Leio" lê da entrada um valor simples de cada vez: um número, um lógico, um caractere ou um texto. Uma lista, um registro, uma enumeração ou um "talvez" não têm uma forma única de se escrever na entrada, e a Lavra não adivinha uma. Leia os itens um por um e ponha cada um no lugar com "ganha".

## Errado

```lavra
Para começar:
    As notas, uma lista de inteiros, começam vazias.
    Leio as notas.
    Escrevo as notas.
```

## Certo

```lavra
Para começar:
    As notas, uma lista de inteiros, começam vazias.
    Repito 3 vezes: leio um inteiro e as notas ganham o resultado.
    Escrevo as notas.
```

```entrada
7
8
9
```
