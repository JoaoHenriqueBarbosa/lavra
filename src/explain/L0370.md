# L0370: Tipo qualquer que a chamada não decide

Numa função genérica, cada tipo qualquer do cabeçalho se decide em cada chamada, pelo tipo dos argumentos: chamar "inverter as notas" com uma lista de inteiros faz de "coisa" um inteiro. Se o tipo qualquer só aparece no que a função devolve, nenhum argumento o decide, e a chamada não tem como saber que função é. O mesmo acontece quando o argumento ainda não tem tipo conhecido. Faça o tipo qualquer aparecer num parâmetro.

## Errado

```lavra
Para criar, devolvendo uma lista de itens quaisquer:
    Os novos, uma lista de itens, são vazios.
    Devolvo os novos.

Para começar:
    As coisas são o resultado de criar.
    Escrevo as coisas.
```

## Certo

```lavra
Para duplicar a lista, sendo a lista uma lista de itens quaisquer emprestada, devolvendo uma lista de itens:
    Os novos, uma lista de itens, começam vazios.
    Repito 2 vezes:
        Para cada peça da lista: os novos ganham uma cópia da peça.
    Devolvo os novos.

Para começar:
    As notas são 7, 8 e 9.
    As coisas são o resultado de duplicar as notas.
    Escrevo as coisas.
```
