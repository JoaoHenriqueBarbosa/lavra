# L0318: Nome no singular com uma coleção

Nome no singular guarda um valor só; o plural é o que marca coleção. Um nome no singular pode guardar uma coleção, como "a fila", mas precisa dizer isso no aposto, para que a forma do nome não engane quem lê. Use um nome no plural ou diga no aposto que é uma lista: "A fila, uma lista de inteiros, começa com 3 e 8."

## Errado

```lavra
Para começar:
    A fila começa com 3 e 8.
    A fila ganha 5.
    Escrevo a fila.
```

## Certo

```lavra
Para começar:
    A fila, uma lista de inteiros, começa com 3 e 8.
    A fila ganha 5.
    Escrevo a fila.
```
