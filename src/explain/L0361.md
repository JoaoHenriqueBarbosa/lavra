# L0361: Conta entre tipos diferentes

Os dois lados de uma conta têm o mesmo tipo: a Lavra não promove inteiro a real nem encolhe real a inteiro por conta própria. Número escrito se adapta ao outro lado ("2 vezes a taxa"), mas nome não muda de tipo sozinho. Converta um dos lados com "como", e assim fica escrito em que tipo a conta é feita.

## Errado

```lavra
Para começar:
    A quantidade é 3.
    O preço é 2,5.
    Escrevo a quantidade vezes o preço.
```

## Certo

```lavra
Para começar:
    A quantidade é 3.
    O preço é 2,5.
    Escrevo a quantidade como real vezes o preço.
```
