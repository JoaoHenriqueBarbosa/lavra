# L0372: Verbo de "que se ..." que o programa não define

"uma coisa qualquer que se mede" pede, do tipo de quem chama, o verbo "medir". Esse verbo tem de existir no programa, definido para algum tipo ("Para medir a conta, ..."), e vem escrito na 3ª pessoa do presente, concordando com o tipo ("que se mede", "coisas quaisquer que se medem"). Se nenhum verbo do programa se conjuga assim, não há o que pedir. Confira a grafia do verbo, ou defina-o.

## Errado

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para anunciar a coisa, sendo a coisa uma coisa qualquer que se pesa emprestada:
    Escrevo o resultado de medir a coisa.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
```

## Certo

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para anunciar a coisa, sendo a coisa uma coisa qualquer que se mede emprestada:
    Escrevo o resultado de medir a coisa.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
    Anuncio a poupança.
```
