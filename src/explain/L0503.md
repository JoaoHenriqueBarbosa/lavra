# L0503: Nome que nunca é usado

Um nome declarado e nunca lido costuma ser engano: um valor calculado que ficou esquecido, ou um nome escrito diferente do que se queria usar. Vale para constantes, variáveis, itens de laço e parâmetros. Use o valor, ou apague a declaração; num parâmetro que a regência pede mas a função não usa, escreva a palavra sem tipo no cabeçalho, e ela vira complemento fixo.

## Errado

```lavra
Para começar:
    O preço é 30.
    A taxa é 5.
    Escrevo o preço.
```

## Certo

```lavra
Para começar:
    O preço é 30.
    A taxa é 5.
    Escrevo o preço mais a taxa.
```
