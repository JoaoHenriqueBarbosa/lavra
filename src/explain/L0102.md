# L0102: Dois "Para começar"

O "Para começar" é o ponto de entrada do programa: a execução começa nele, e por isso só pode haver um. Com dois, não haveria como saber qual roda. Junte as orações num único "Para começar", ou ponha o trecho que se repete numa função com nome próprio e chame-a de lá.

## Errado

```lavra
Para começar:
    Escrevo "Bom dia".

Para começar:
    Escrevo "Boa noite".
```

## Certo

```lavra
Para começar:
    Escrevo "Bom dia".
    Escrevo "Boa noite".
```
