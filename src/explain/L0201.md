# L0201: Tipo definido no plural

Um tipo se define no singular, com "um" ou "uma": "Uma posição é um registro de:". O compilador gera o plural a partir do singular ("as posições", "uma lista de posições"), e o artigo da definição fixa o gênero que os artigos do programa vão conferir. Para uma ideia que se diria no plural, como "coordenadas", escolha um nome no singular.

## Errado

```lavra
Umas coordenadas é um registro de:
    a latitude, um real;
    a longitude, um real.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Uma posição é um registro de:
    a latitude, um real;
    a longitude, um real.

Para começar:
    O farol é uma posição com a latitude 23,0 e a longitude 45,4.
    Escrevo a latitude do farol.
```
