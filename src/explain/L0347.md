# L0347: Conversão impossível

"como" converte entre números e de qualquer valor simples (número, lógico, caractere) para texto. O caminho inverso não é conversão: um texto pode não ser número nenhum, e a Lavra não decide em silêncio o que fazer com "abc". Para obter um número da entrada, leia direto num lugar do tipo certo ("Leio a idade", com a idade inteira) ou peça o tipo à leitura ("Leio um inteiro"): ela confere o que foi digitado e, se não for número, falha com mensagem.

## Errado

```lavra
Para começar:
    A idade começa em "".
    Leio a idade.
    Escrevo a idade como inteiro mais 1.
```

## Certo

```lavra
Para começar:
    A idade começa em 0.
    Leio a idade.
    Escrevo a idade mais 1.
```

```entrada
30
```
