# L0347: Conversão impossível

"como" converte entre números, de qualquer valor simples (número, lógico, caractere) para texto, de texto para número, e entre o caractere e o código dele. Fora disso não há conversão: uma lista não vira número, um texto não vira lógico, um registro não vira nada. Quase sempre o que se quer é outra operação: o tamanho da lista, uma comparação que dê o lógico, um campo do registro.

## Errado

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Escrevo as notas como inteiro.
```

## Certo

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Escrevo o tamanho das notas.
```
