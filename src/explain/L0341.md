# L0341: Item de valor que não é coleção

Só lista e texto têm itens: "a primeira das notas" é a primeira nota, e num texto a posição dá o caractere. Um número não é uma fileira de algarismos, então "o primeiro do código" não tem o que tirar. Se os algarismos importam, guarde o valor como texto, entre aspas, ou converta com "como texto".

## Errado

```lavra
Para começar:
    O código é 4521.
    Escrevo o primeiro do código.
```

## Certo

```lavra
Para começar:
    O código é "4521".
    Escrevo o primeiro do código.
```
