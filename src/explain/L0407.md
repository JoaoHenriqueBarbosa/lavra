# L0407: Valor usado enquanto está confiado a outro nome

", confiada" entrega o lugar a um nome com exclusividade, para ele mudar o que está lá: enquanto essa referência durar, o dono não se usa, nem para ler, porque o valor pode estar no meio de uma mudança. A referência vale até o fim do bloco em que foi declarada (não até o último uso). Use o valor pela própria referência, ou feche o bloco antes de voltar ao dono. A referência de leitura (", emprestada") é menos exigente: o dono continua podendo ser lido, só não muda.

## Errado

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    Se o tamanho das notas for maior que 0:
        A dona é as notas, confiada.
        A dona ganha 10.
        Escrevo as notas.
```

## Certo

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    Se o tamanho das notas for maior que 0:
        A dona é as notas, confiada.
        A dona ganha 10.
    Escrevo as notas.
```
