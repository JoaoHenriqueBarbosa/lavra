# L0103: Faltou o bloco recuado depois dos dois-pontos

Os dois-pontos anunciam um bloco: as orações que dependem do "Se", do laço ou da função vêm na linha de baixo, com mais recuo que a linha dos dois-pontos. Sem o recuo, não há como saber quais orações estão dentro do bloco e quais vêm depois dele. Recue as linhas do bloco (quatro espaços) ou, se o bloco for um período só, escreva-o na mesma linha, depois dos dois-pontos.

## Errado

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for maior que 5:
    Escrevo "alto".
```

## Certo

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for maior que 5:
        Escrevo "alto".
```
