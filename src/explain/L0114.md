# L0114: Verbo da condição fora do futuro do subjuntivo

A condição de um "Se" ou de um "Enquanto" vai no futuro do subjuntivo, como no português: "se o saldo for maior que 100", não "se o saldo é maior que 100". O indicativo afirma um fato; o subjuntivo levanta a hipótese que a condição confere, e é esse modo que marca a oração como condição. Use "for" ("forem" no plural); um predicado do programa também vai no subjuntivo, e "Para o guarda ver o ladrão" vira a condição "Se o guarda vir o ladrão".

## Errado

```lavra
Para começar:
    O saldo é 120.
    Se o saldo é maior que 100:
        Escrevo "acima do teto".
```

## Certo

```lavra
Para começar:
    O saldo é 120.
    Se o saldo for maior que 100:
        Escrevo "acima do teto".
```
