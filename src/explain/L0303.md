# L0303: Registro recursivo por lista

Uma lista guarda os itens fora do registro, então um registro com uma lista de si mesmo teria tamanho finito, como uma pessoa que guarda a lista dos filhos; mesmo assim, a Lavra ainda não monta esse tipo. Enquanto isso, guarde na lista o que identifica cada um dos outros: o nome, ou a posição deles numa lista de fora.

## Errado

```lavra
Uma pessoa é um registro de:
    o nome, um texto;
    os filhos, uma lista de pessoas.

Para começar:
    Escrevo "família".
```

## Certo

```lavra
Uma pessoa é um registro de:
    o nome, um texto;
    os filhos, uma lista de textos.

Para começar:
    A mãe é uma pessoa com o nome "Rosa" e os filhos "Ana".
    Escrevo os filhos da mãe.
```
