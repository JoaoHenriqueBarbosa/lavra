# L0303: Registro recursivo por lista

Este código acusava o registro com uma lista de si mesmo, quando a Lavra ainda não montava esse tipo. Hoje ela monta: "os filhos, uma lista de pessoas" é um campo válido, e o mesmo vale para a enumeração com uma lista dela num caso. Nenhum programa chega mais a este código, que fica reservado. O tipo que contém a si mesmo sem lista continua sendo erro, o L0302.
