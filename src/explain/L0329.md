# L0329: Valor solto onde o parâmetro é confiado

Um parâmetro "confiado" recebe o lugar de quem chama, não uma cópia do valor, para que a função possa mudá-lo e a mudança fique lá quando ela acabar. Um número escrito ou uma conta não têm lugar onde a mudança fique. Declare um nome com "começa em", que pode mudar, e passe esse nome.

## Errado

```lavra
Para render o saldo, sendo o saldo um real confiado:
    O saldo cresce o saldo vezes 0,05.

Para começar:
    Rendo 1000,0.
```

## Certo

```lavra
Para render o saldo, sendo o saldo um real confiado:
    O saldo cresce o saldo vezes 0,05.

Para começar:
    O saldo começa em 1000,0.
    Rendo o saldo.
    Escrevo o saldo.
```
