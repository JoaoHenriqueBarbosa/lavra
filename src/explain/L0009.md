# L0009: Hexadecimal com sinal

O hexadecimal escreve um padrão de bits, e por isso não leva sinal: "-0x10" misturaria o padrão com uma conta. Para um valor negativo, escreva-o em decimal ("-16") ou faça a conta por extenso: "o negativo de 0x10".

## Errado

```lavra
Para começar:
    O ajuste é -0x10.
    Escrevo o ajuste.
```

## Certo

```lavra
Para começar:
    O ajuste é o negativo de 0x10.
    Escrevo o ajuste.
```
