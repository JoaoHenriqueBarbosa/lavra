# L0151: Verbo da própria língua redefinido

Os verbos da Lavra têm sentido fixo: os que o programa narra na 1ª pessoa ("escrever", "ler", "tomar", "devolver", "desistir", "parar", "pular", "repetir") e os que têm o dado como sujeito ("ser", "começar", "virar", "crescer", "diminuir", "ganhar", "perder"). Uma função com o mesmo infinitivo faria "Escrevo o recado." querer dizer duas coisas, e quem lê não saberia qual delas o programa executa. Escolha outro verbo para a sua função.

## Errado

```lavra
Para escrever o recado, sendo o recado um texto:
    Escrevo "Recado: " seguido do recado.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para anunciar o recado, sendo o recado um texto:
    Escrevo "Recado: " seguido do recado.

Para começar:
    Anuncio "a reunião começou".
```
