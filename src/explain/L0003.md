# L0003: Caractere sem aspas simples de fechamento

Um caractere se escreve entre aspas simples, com a letra e as duas aspas na mesma linha: 'a', '7'. Uma aspa simples no fim da linha abre um caractere que nunca fecha; costuma acontecer ao tentar escrever a quebra de linha apertando Enter entre as aspas. A quebra de linha tem escape próprio, '\n', como a tabulação tem '\t'.

## Errado

```lavra
Para começar:
    A quebra é '
    Escrevo "um" seguido da quebra seguido de "dois".
```

## Certo

```lavra
Para começar:
    A quebra é '\n'.
    Escrevo "um" seguido da quebra seguido de "dois".
```
