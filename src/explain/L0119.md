# L0119: "Desisto" sem o motivo

"Desisto" encerra a função com uma falha, e toda falha diz o motivo, num texto depois de "com". É o motivo que quem chamou a função, ou quem usa o programa, vai ler: uma falha sem ele não diria o que deu errado. Escreva o motivo: desisto com "idade negativa".

## Errado

```lavra
Para começar:
    Leio um inteiro, e a idade é o resultado.
    Se a idade for menor que 0: desisto.
    Escrevo a idade.
```

## Certo

```lavra
Para começar:
    Leio um inteiro, e a idade é o resultado.
    Se a idade for menor que 0: desisto com "idade negativa".
    Escrevo a idade.
```

```entrada
30
```
