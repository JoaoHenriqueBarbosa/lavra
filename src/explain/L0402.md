# L0402: Constante entregue

Uma constante do nível de fora pertence ao programa inteiro: todas as funções a leem, do começo ao fim. Se ela for texto, lista ou registro, entregá-la (a um parâmetro sem particípio, a outro nome, a uma lista) tiraria o valor de todo o resto do programa, e por isso a Lavra recusa. Entregue uma cópia ("Anuncio uma cópia da saudação."), ou, se a função só precisa ler, peça a constante emprestada no cabeçalho ("sendo a frase um texto emprestado").

## Errado

```lavra
A saudação é "Bom dia".

Para anunciar a frase, sendo a frase um texto:
    Escrevo a frase seguido de "!".

Para começar:
    Anuncio a saudação.
```

## Certo

```lavra
A saudação é "Bom dia".

Para anunciar a frase, sendo a frase um texto:
    Escrevo a frase seguido de "!".

Para começar:
    Anuncio uma cópia da saudação.
```
