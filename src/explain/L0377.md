# L0377: "invocar" o que não é verbo, ou com os valores errados

"invocar" só vale para um verbo guardado, isto é, um valor cujo tipo é "um verbo ...": um parâmetro desse tipo, ou um nome que recebeu um infinitivo. E os valores depois de "com" são os que o tipo do verbo pede, na mesma quantidade e na mesma ordem. Uma função do programa não se invoca: chama-se pelo nome ("Dobro o saldo.", "o resultado de dobrar 2").

## Errado

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para começar:
    A ação é dobrar.
    Escrevo o resultado de invocar a ação com 1 e 2.
```

## Certo

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para começar:
    A ação é dobrar.
    Escrevo o resultado de invocar a ação com 21.
```
