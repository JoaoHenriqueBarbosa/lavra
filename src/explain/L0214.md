# L0214: "vazio" que não concorda

"Vazio" é adjetivo e concorda com o nome que declara, como em português: "a fila começa vazia", "as compras começam vazias", "os pedidos começam vazios". A concordância é a conferência redundante da Lavra: ela confirma que a frase fala do nome que você declarou. Troque pela forma que concorda em gênero e número.

## Errado

```lavra
Para começar:
    As compras começam vazio.
    As compras ganham "pão".
    Escrevo as compras.
```

## Certo

```lavra
Para começar:
    As compras começam vazias.
    As compras ganham "pão".
    Escrevo as compras.
```
