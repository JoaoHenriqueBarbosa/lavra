# L0379: Valor de reserva onde nada pode faltar

", ou VALOR" depois de um item diz o que usar quando o item não existe, e isso só acontece com a chave de um mapa: "o item "Ana" das idades, ou 0" dá 0 se o mapa não tem a chave "Ana". Numa lista, a posição que não existe é falha de execução, e não um caso previsto: o programa confere antes com "o tamanho de". Num nome ou num campo, o valor está sempre lá. Tire o valor de reserva, ou confira a posição antes.

## Errado

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Escrevo o item 5 das notas, ou 0.
```

## Certo

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Se o tamanho das notas for pelo menos 5: escrevo o item 5 das notas.
    Senão: escrevo 0.
```
