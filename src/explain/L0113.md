# L0113: Verbo que não concorda com o sujeito

O verbo concorda em número com o sujeito, como no português: "a lista ganha", "as compras ganham". Na Lavra, a concordância é uma checagem redundante de propósito: o plural do nome diz que ele é uma coleção, e um verbo no singular sinaliza que alguém se confundiu sobre o que o nome guarda. Ponha o verbo no número do sujeito; o mesmo vale para "for" e "forem" nas condições.

## Errado

```lavra
Para começar:
    As compras começam vazias.
    As compras ganha "pão".
    Escrevo as compras.
```

## Certo

```lavra
Para começar:
    As compras começam vazias.
    As compras ganham "pão".
    Escrevo as compras.
```
