# L0910: "o último" de coleção vazia

Uma coleção vazia não tem último item, e pedir "o último" (ou "a última") dela interrompe o programa. Isso costuma acontecer com uma lista que começou vazia e que um filtro não encheu. Confira o tamanho antes de pedir o último, como no exemplo certo.

## Errado

```lavra
Para começar:
    Os pedidos são 12, 40 e 7.
    Os grandes começam vazios.
    Para cada pedido dos pedidos:
        Se o pedido for maior que 100: os grandes ganham o pedido.
    Escrevo "último grande: " seguido do último dos grandes.
```

## Certo

```lavra
Para começar:
    Os pedidos são 12, 40 e 7.
    Os grandes começam vazios.
    Para cada pedido dos pedidos:
        Se o pedido for maior que 100: os grandes ganham o pedido.
    Se o tamanho dos grandes for igual a 0: escrevo "nenhum pedido grande".
    Senão: escrevo "último grande: " seguido do último dos grandes.
```
