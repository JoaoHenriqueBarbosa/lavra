# L0176: Particípio sem tipo, com nome que não é de tipo

Quando o nome do parâmetro é o próprio nome do tipo, o cabeçalho dispensa a repetição e o particípio vem direto: "sendo a prova emprestada" vale por "sendo a prova uma prova emprestada", e o mesmo com "confiada". Isso só cabe quando o nome é de um registro, de uma enumeração ou de um tipo da língua ("o texto", "o inteiro"). Com qualquer outro nome o particípio fica sem tipo a que se ligar, e o compilador não adivinha qual seria. Diga o tipo antes do particípio.

## Errado

```lavra
Para medir a carta, sendo a carta emprestada, devolvendo um inteiro:
    Devolvo o tamanho da carta.

Para começar:
    Escrevo o resultado de medir "oi".
```

## Certo

```lavra
Para medir a carta, sendo a carta um texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho da carta.

Para começar:
    Escrevo o resultado de medir "oi".
```
