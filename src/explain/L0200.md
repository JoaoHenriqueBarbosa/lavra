# L0200: Faltou o nome do tipo

Um registro ou uma enumeração se define com artigo indefinido e um substantivo: "Uma conta é um registro de:". O nome do tipo é uma palavra, não um texto entre aspas: o compilador tira dela o plural ("as contas", "uma lista de contas"), e o artigo da definição dá o gênero. Escreva o nome sem aspas, logo depois do artigo.

## Errado

```lavra
Uma "conta" é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo a carteira.
```
