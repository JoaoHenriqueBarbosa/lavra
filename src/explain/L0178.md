# L0178: Arquivo que não se conseguiu trazer

`Uso o arquivo "contas.lav".` lê o arquivo do disco na hora de compilar, e o caminho conta a partir da pasta do arquivo que pede (não da pasta em que o comando roda). O erro diz o motivo, e a dica mostra onde o compilador procurou: o arquivo não existe ali, não há permissão para lê-lo, o caminho é de uma pasta, ou o conteúdo não é texto. No navegador (o playground) não há disco, e nenhum arquivo se traz. Confira o nome e a pasta; para subir uma pasta, `Uso o arquivo "../comum/contas.lav".`
