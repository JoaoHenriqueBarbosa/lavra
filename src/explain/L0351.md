# L0351: Campo repetido na construção

Na construção de um registro, ou de um caso com campos, cada campo recebe valor uma vez só. Campo repetido quase sempre é outro campo escrito com o nome trocado, como o "x" no lugar do "y", e aceitar o segundo valor apagaria o primeiro sem aviso. Diga cada campo uma vez, com o nome da definição.

## Errado

```lavra
Um ponto é um registro de:
    x, um real;
    y, um real.

Para começar:
    O destino é um ponto com x 3,0 e x 4,0.
    Escrevo o destino.
```

## Certo

```lavra
Um ponto é um registro de:
    x, um real;
    y, um real.

Para começar:
    O destino é um ponto com x 3,0 e y 4,0.
    Escrevo o destino.
```
