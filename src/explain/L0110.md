# L0110: "Senão se" sem vírgula

Na cadeia de condições, "Senão, se" leva vírgula, como no português escrito: ela separa o "senão" da nova condição que começa com "se". A Lavra trata a pontuação como parte da gramática, e a forma sem vírgula não é aceita. Escreva "Senão, se ...:".

## Errado

```lavra
Para começar:
    A nota é 6.
    Se a nota for pelo menos 7:
        Escrevo "aprovado".
    Senão se a nota for pelo menos 5:
        Escrevo "recuperação".
    Senão:
        Escrevo "reprovado".
```

## Certo

```lavra
Para começar:
    A nota é 6.
    Se a nota for pelo menos 7:
        Escrevo "aprovado".
    Senão, se a nota for pelo menos 5:
        Escrevo "recuperação".
    Senão:
        Escrevo "reprovado".
```
