# L0315: Vários valores com aposto que não é lista

Vários valores separados por vírgula e "e" formam uma lista, e o aposto diz o tipo do nome inteiro, não o de cada item. Um aposto como "um inteiro" promete um valor só, e o que vem escrito são vários. Diga no aposto que é uma lista: "uma lista de inteiros".

## Errado

```lavra
Para começar:
    As notas, um inteiro, são 7, 8 e 9.
    Escrevo as notas.
```

## Certo

```lavra
Para começar:
    As notas, uma lista de inteiros, são 7, 8 e 9.
    Escrevo as notas.
```
