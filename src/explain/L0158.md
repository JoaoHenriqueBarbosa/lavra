# L0158: Tipo devolvido sem artigo indefinido

Depois de "devolvendo" vem o tipo do valor, e tipo na Lavra se diz com artigo indefinido no singular: "devolvendo um inteiro", "devolvendo uma lista de reais". O artigo indefinido é o que separa um tipo de um nome ("um inteiro" é um tipo, "o total" é um valor), e é com ele que o gênero do tipo se confere. Ponha "um" ou "uma" antes do tipo.

## Errado

```lavra
Para dobrar x, sendo x um inteiro, devolvendo inteiro:
    Devolvo x vezes 2.

Para começar:
    Escrevo o resultado de dobrar 21.
```

## Certo

```lavra
Para dobrar x, sendo x um inteiro, devolvendo um inteiro:
    Devolvo x vezes 2.

Para começar:
    Escrevo o resultado de dobrar 21.
```
