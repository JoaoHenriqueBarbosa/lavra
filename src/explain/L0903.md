# L0903: Deslocamento fora da faixa

Um deslocamento de bits vai de 0 até o número de bits do tipo menos 1: num byte, de 0 a 7; num inteiro, de 0 a 63. Fora disso, ou com valor negativo, o resultado não é bem definido (cada processador faz uma coisa), e a Lavra interrompe o programa em vez de escolher um em silêncio. Confira a contagem: os bits contam a partir de 0, ao contrário das posições de lista, que começam em 1.

## Errado

```lavra
Para começar:
    A luz, um byte, é 1.
    Para cada casa de 0 até 8:
        Escrevo o deslocamento da luz pela casa à esquerda.
```

## Certo

```lavra
Para começar:
    A luz, um byte, é 1.
    Para cada casa de 0 até 7:
        Escrevo o deslocamento da luz pela casa à esquerda.
```
