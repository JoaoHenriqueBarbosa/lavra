# L0208: Faltou o nome do caso

Depois do artigo, cada caso de uma enumeração leva o nome, uma palavra sem aspas: "um verde". O caso não é um texto, é um nome que o programa usa para construir valores ("O semáforo começa em um vermelho.") e para perguntar por eles ("Sendo um verde:"). Tire as aspas e escreva o nome.

## Errado

```lavra
Um sinal é um destes:
    um "verde";
    um "amarelo";
    um "vermelho".

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Um sinal é um destes:
    um verde;
    um amarelo;
    um vermelho.

Para começar:
    O semáforo começa em um vermelho.
    O semáforo vira um verde.
    Escrevo o semáforo.
```
