# L0173: Biblioteca pedida fora da forma

Uma biblioteca entra no programa por uma frase só, no nível de fora, antes do que a usa: "Uso a biblioteca de textos.". O "de" diz qual biblioteca, e o ponto fecha a frase. Sem essa forma, a frase não traz nada.

## Errado

```lavra
Uso a biblioteca textos.

Para começar:
    Escrevo o resultado de aparar "  lavra  ".
```

## Certo

```lavra
Uso a biblioteca de textos.

Para começar:
    Escrevo o resultado de aparar "  lavra  ".
```
