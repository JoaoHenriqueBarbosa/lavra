# L0210: Campo de caso sem artigo

Os campos de um caso de enumeração vêm depois de "com" como nomes com artigo, no mesmo molde da construção do valor: "um círculo, com o raio, um real" define, "um círculo com o raio 2,0" constrói. É o artigo que dá ao campo o gênero e o número que a concordância confere, e dentro de "Sendo um círculo:" o campo vira um nome do bloco ("o raio"). O símbolo sem artigo ("x, um real;") só vale como campo de registro; num caso, dê ao campo um nome com artigo.

## Errado

```lavra
Uma forma é uma destas:
    um círculo, com r, um real;
    um ponto.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Uma forma é uma destas:
    um círculo, com o raio, um real;
    um ponto.

Para começar:
    A roda é um círculo com o raio 0,3.
    Conforme a roda:
        Sendo um círculo: escrevo 2 vezes 3,14159 vezes o raio.
        Sendo um ponto: escrevo 0,0.
```
