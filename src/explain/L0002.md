# L0002: Texto sem aspas de fechamento

Um texto abre e fecha as aspas na mesma linha. Sem as aspas de fechamento, o léxico não tem como saber onde o texto termina e toma o resto da linha, ponto final inclusive, como parte dele. Feche as aspas antes do ponto; para um texto longo, junte as partes com "seguido de", e para uma quebra de linha dentro do texto, use o escape "\n".

## Errado

```lavra
Para começar:
    O nome é "Ana.
    Escrevo o nome.
```

## Certo

```lavra
Para começar:
    O nome é "Ana".
    Escrevo o nome.
```
