# L0378: Verbo escrito ou comparado

Um verbo guardado é uma ação, e não um dado: não tem forma escrita nem igualdade que faça sentido. Com ele se fazem três coisas: guardar num nome, passar a uma função e invocar. O que se escreve e se compara é o que ele devolve quando é invocado.

## Errado

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para começar:
    A ação é dobrar.
    Escrevo a ação.
```

## Certo

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para começar:
    A ação é dobrar.
    Escrevo o resultado de invocar a ação com 21.
```
