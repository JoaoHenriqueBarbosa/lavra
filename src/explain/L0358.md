# L0358: Texto somado

Texto não se soma: se junta, com "seguido de". "mais" é a conta de números, e a Lavra mantém as duas operações separadas para que nunca seja preciso adivinhar se "10" mais 5 dá 15 ou "105". "seguido de" aceita do lado direito qualquer valor simples, inclusive número ("seguido do total").

## Errado

```lavra
Para começar:
    O nome é "Ana".
    Escrevo "Olá, " mais o nome.
```

## Certo

```lavra
Para começar:
    O nome é "Ana".
    Escrevo "Olá, " seguido do nome.
```
