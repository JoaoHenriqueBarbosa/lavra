# L0204: Campo repetido na definição

Cada campo de um registro, ou de um caso de enumeração, tem nome único, porque é pelo nome que ele se lê ("o telefone da amiga") e se preenche na construção ("com o telefone ..."). Dois campos com o mesmo nome deixariam essas frases ambíguas, mesmo com tipos diferentes. Dê nomes diferentes aos campos, ou use um campo no plural com uma lista ("os telefones, uma lista de textos").

## Errado

```lavra
Um contato é um registro de:
    o nome, um texto;
    o telefone, um texto;
    o telefone, um texto.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Um contato é um registro de:
    o nome, um texto;
    o telefone, um texto;
    o celular, um texto.

Para começar:
    A amiga é um contato com o nome "Ana", o telefone "3333-1000" e o celular "99999-2000".
    Escrevo o celular da amiga.
```
