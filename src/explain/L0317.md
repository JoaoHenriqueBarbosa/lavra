# L0317: Nome no plural com um valor só

Na Lavra, nome no plural é coleção: "os pontos" guarda vários itens, e os verbos concordam com isso. Sem aposto, um valor só num nome no plural vira uma lista de um item; com um aposto que diz um valor só, como "um inteiro", o nome e o tipo se contradizem. Para um valor só, use um nome no singular ("a pontuação"); para uma coleção, diga no aposto "uma lista de ...".

## Errado

```lavra
Para começar:
    Os pontos, um inteiro, começam em 0.
    Os pontos crescem 10.
    Escrevo os pontos.
```

## Certo

```lavra
Para começar:
    A pontuação, um inteiro, começa em 0.
    A pontuação cresce 10.
    Escrevo a pontuação.
```
