# L0375: Tipo qualquer usado num verbo que o cabeçalho não pediu

Dentro de uma função genérica, um valor de tipo qualquer só faz o que vale para todo tipo. Um verbo do programa não vale: "medir" está definido para alguns tipos, e a função seria chamada também com os outros. Para usar o verbo, peça-o no cabeçalho: "uma coisa qualquer que se mede". Daí em diante a função só aceita os tipos que se medem, e cada chamada é conferida.

## Errado

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para anunciar a coisa, sendo a coisa uma coisa qualquer emprestada:
    Escrevo o resultado de medir a coisa.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
    Anuncio a poupança.
```

## Certo

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para anunciar a coisa, sendo a coisa uma coisa qualquer que se mede emprestada:
    Escrevo o resultado de medir a coisa.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
    Anuncio a poupança.
```
