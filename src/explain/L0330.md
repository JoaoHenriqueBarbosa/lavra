# L0330: Comparação de ordem entre valores sem ordem

"maior que", "menor que", "pelo menos" e "no máximo" comparam valores que têm ordem: números, caracteres e textos. Os casos de uma enumeração, os lógicos, as listas e os registros não têm ordem natural, e a Lavra não inventa uma a partir da ordem em que os casos foram escritos. Pergunte pelo caso ("Se o pedido for um grande"), compare com "igual a" ou "diferente de", ou compare um número tirado do valor.

## Errado

```lavra
Um tamanho é um destes:
    um pequeno;
    um médio;
    um grande.

Para começar:
    O pedido é um grande.
    Se o pedido for maior que um médio: escrevo "cobra a mais".
```

## Certo

```lavra
Um tamanho é um destes:
    um pequeno;
    um médio;
    um grande.

Para começar:
    O pedido é um grande.
    Se o pedido for um grande: escrevo "cobra a mais".
```
