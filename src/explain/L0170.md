# L0170: Real com tamanho inválido

Um real tem 64 bits, ou 32 com "de 32 bits": são os dois tamanhos de número com vírgula que a Lavra compila. Os 8 e os 16 bits valem para inteiros e naturais, não para reais. Escreva "um real de 32 bits", ou só "um real", que tem 64.

## Errado

```lavra
Para começar:
    A temperatura, um real de 16 bits, é 21,5.
    Escrevo a temperatura.
```

## Certo

```lavra
Para começar:
    A temperatura, um real de 32 bits, é 21,5.
    Escrevo a temperatura.
```
