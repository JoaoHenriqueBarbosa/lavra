# L0121: Verbo no infinitivo onde o programa age

O infinitivo é a forma que define: "Para saudar a pessoa, ...:" é o cabeçalho da função. Para executá-la, o programa narra em 1ª pessoa, como em toda ação, e "saudar" vira "saúdo". O infinitivo só volta quando o programa usa o valor de uma função: "o resultado de elevar 2 a 10".

## Errado

```lavra
Para saudar a pessoa, sendo a pessoa um texto:
    Escrevo "Olá, " seguido da pessoa.

Para começar:
    Saudar "Ana".
```

## Certo

```lavra
Para saudar a pessoa, sendo a pessoa um texto:
    Escrevo "Olá, " seguido da pessoa.

Para começar:
    Saúdo "Ana".
```
