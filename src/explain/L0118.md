# L0118: Campo que nenhum registro tem

Depois de um nome, o "de" lê um campo de registro: "o saldo da carteira" é o campo "saldo" do valor "a carteira". Se nenhum registro do programa tem um campo com aquele nome, o "de" não tem o que ler; a dica do erro lista os campos que existem, ou sugere o mais parecido. Use o nome do campo como está na definição do registro.

## Errado

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo o nome da carteira.
```

## Certo

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo o titular da carteira.
```
