# L0900: Estouro de inteiro

Cada tipo inteiro tem uma faixa (um byte vai de 0 a 255, um natural nunca fica negativo), e toda conta com inteiros é conferida contra ela. Quando o resultado sai da faixa, o programa para com erro de execução, em vez de dar a volta em silêncio e seguir com um número errado. Confira antes de fazer a conta, como no exemplo certo, ou use um tipo de faixa maior.

## Errado

```lavra
Para começar:
    O estoque, um natural, começa em 3.
    O estoque diminui 5.
    Escrevo o estoque.
```

## Certo

```lavra
Para começar:
    O estoque, um natural, começa em 3.
    Se o estoque for pelo menos 5: o estoque diminui 5.
    Senão: escrevo "faltam itens".
    Escrevo o estoque.
```
