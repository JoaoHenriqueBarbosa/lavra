# L0369: Referência a um valor sem lugar

Uma referência aponta para um lugar que já existe e tem dono: um nome, um campo ("o saldo da conta") ou um item ("a primeira das contas"). O resultado de uma conta ou de uma chamada é um valor feito na hora, que não mora em lugar nenhum: não há o que emprestar. Sem o particípio, o nome simplesmente fica dono do valor, que é o que se quer nesse caso.

## Errado

```lavra
Para começar:
    O dobro é 2 vezes 21, emprestado.
    Escrevo o dobro.
```

## Certo

```lavra
Para começar:
    O dobro é 2 vezes 21.
    Escrevo o dobro.
```
