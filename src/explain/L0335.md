# L0335: "houver" de valor que não é talvez

"Se houver apelido" pergunta se um valor declarado com "talvez" está presente. Um nome declarado sem "talvez" sempre tem valor, então a pergunta não faz sentido, e a Lavra recusa em vez de aceitar uma condição que é sempre verdadeira. Se o valor pode mesmo faltar, declare com "talvez" no aposto; se não pode, tire a condição.

## Errado

```lavra
Para começar:
    O apelido é "Zé".
    Se houver apelido: escrevo o apelido.
```

## Certo

```lavra
Para começar:
    O apelido, talvez um texto, começa em nada.
    O apelido vira "Zé".
    Se houver apelido: escrevo o apelido.
```
