# L0321: "cresce" ou "diminui" em quem não é número

"cresce" e "diminui" fazem conta com o valor, somando ou subtraindo, e conta só se faz com número: texto não se soma, se junta. Monte o texto novo com "seguido de" e guarde-o com "vira"; para pôr um item numa lista, o verbo é "ganha".

## Errado

```lavra
Para começar:
    O nome começa em "Ana".
    O nome cresce " Maria".
    Escrevo o nome.
```

## Certo

```lavra
Para começar:
    O nome começa em "Ana".
    O nome vira o nome seguido de " Maria".
    Escrevo o nome.
```
