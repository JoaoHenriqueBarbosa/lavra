# L0314: Nome com uma letra só

Artigo marca nome, e nome é palavra: "o saldo", "a taxa". Uma letra sozinha não é palavra, é símbolo, como na matemática, e símbolo se escreve sem artigo, ao declarar e ao usar. Tire o artigo ("X é 3.", "Escrevo x.") ou dê ao valor um nome de verdade ("A largura é 3.").

## Errado

```lavra
Para começar:
    O x é 3.
    Escrevo o x vezes 2.
```

## Certo

```lavra
Para começar:
    X é 3.
    Escrevo x vezes 2.
```
