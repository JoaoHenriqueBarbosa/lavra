# L0307: Intervalo de "Para cada" que não é de inteiros

"Para cada X de A até B" anda de um em um, e só entre inteiros o próximo valor é bem definido: entre 0,0 e 3,0 há infinitos reais, e nenhum passo é o natural. Por isso as duas pontas do intervalo são inteiras. Percorra inteiros e, dentro do laço, converta o valor com "como real" onde a conta pede um real.

## Errado

```lavra
Para começar:
    Para cada grau de 0,0 até 3,0:
        Escrevo o grau vezes 1,8 mais 32.
```

## Certo

```lavra
Para começar:
    Para cada grau de 0 até 3:
        Escrevo o grau como real vezes 1,8 mais 32.
```
