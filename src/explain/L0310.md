# L0310: Caso tratado duas vezes

Num "Conforme", cada caso vai para um braço só, e um segundo "Sendo" com o mesmo caso nunca rodaria, porque o caso já foi atendido antes. A repetição quase sempre esconde um engano na lista de casos, como um caso escrito no lugar de outro. Deixe cada caso num "Sendo" só; para dar o mesmo bloco a vários casos, junte-os com "ou".

## Errado

```lavra
Um sinal é um destes:
    um verde;
    um amarelo;
    um vermelho.

Para começar:
    O semáforo é um amarelo.
    Conforme o semáforo:
        Sendo um verde: escrevo "siga".
        Sendo um amarelo ou um vermelho: escrevo "pare".
        Sendo um amarelo: escrevo "atenção".
```

## Certo

```lavra
Um sinal é um destes:
    um verde;
    um amarelo;
    um vermelho.

Para começar:
    O semáforo é um amarelo.
    Conforme o semáforo:
        Sendo um verde: escrevo "siga".
        Sendo um amarelo: escrevo "atenção".
        Sendo um vermelho: escrevo "pare".
```
