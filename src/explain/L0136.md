# L0136: "cópia" no masculino

"Uma cópia de X" faz um clone do valor, e "cópia" é feminino: o artigo é "uma", seja qual for o gênero do nome que recebe a cópia ou do valor copiado. O "um cópia" costuma vir da concordância com o nome da esquerda ("o rascunho"), mas o artigo concorda com "cópia". Escreva "uma cópia".

## Errado

```lavra
Para começar:
    A carta é "Querida Ana".
    O rascunho é um cópia da carta.
    Escrevo o rascunho.
    Escrevo a carta.
```

## Certo

```lavra
Para começar:
    A carta é "Querida Ana".
    O rascunho é uma cópia da carta.
    Escrevo o rascunho.
    Escrevo a carta.
```
