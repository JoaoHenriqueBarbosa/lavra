# L0405: Valor entregue enquanto está emprestado

Durante um "Para cada", a coleção está emprestada ao laço, que a percorre item por item. Entregá-la dentro do próprio laço (a um parâmetro sem particípio, a outro nome, a outra lista) é a mudança mais radical de todas: ela trocaria de dono enquanto o laço ainda lê os itens dela. Entregue uma cópia ("uma cópia das tarefas"), ou decida dentro do laço e entregue a coleção depois que ele terminar.

## Errado

```lavra
Para encaminhar as tarefas, sendo as tarefas uma lista de textos:
    Escrevo "encaminhadas: " seguido das tarefas.

Para começar:
    As tarefas são "lavar", "urgente" e "passar".
    Para cada tarefa das tarefas:
        Se a tarefa for igual a "urgente": encaminho as tarefas.
```

## Certo

```lavra
Para encaminhar as tarefas, sendo as tarefas uma lista de textos:
    Escrevo "encaminhadas: " seguido das tarefas.

Para começar:
    As tarefas são "lavar", "urgente" e "passar".
    Para cada tarefa das tarefas:
        Se a tarefa for igual a "urgente": encaminho uma cópia das tarefas.
```
