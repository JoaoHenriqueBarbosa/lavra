# L0376: Verbo que não serve onde se espera outro

O infinitivo de uma função do programa é o próprio verbo como valor: "transformar as notas com dobrar". O tipo do verbo guardado diz o que ele recebe e o que devolve ("um verbo de inteiro para inteiro"), e o verbo passado tem de ser exatamente assim: os mesmos tipos, na mesma ordem, emprestados onde o tipo diz "emprestado". Nem toda função serve de verbo guardado: ficam de fora a genérica, a que pode falhar ("salvo engano") e a que recebe algo confiado. Passe um verbo com a forma esperada, ou escreva uma função pequena com essa forma que chame a outra.

## Errado

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para gritar a frase, sendo a frase um texto emprestado, devolvendo um texto:
    Devolvo a frase seguido de "!".

Para aplicar a ação, sendo a ação um verbo de inteiro para inteiro, devolvendo um inteiro:
    Devolvo o resultado de invocar a ação com 21.

Para começar:
    Escrevo o resultado de aplicar dobrar.
    Escrevo o resultado de aplicar gritar.
```

## Certo

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para gritar a frase, sendo a frase um texto emprestado, devolvendo um texto:
    Devolvo a frase seguido de "!".

Para aplicar a ação, sendo a ação um verbo de inteiro para inteiro, devolvendo um inteiro:
    Devolvo o resultado de invocar a ação com 21.

Para começar:
    Escrevo o resultado de aplicar dobrar.
    Escrevo o resultado de gritar "pronto".
```
