# L0152: 1ª pessoa que já é palavra da língua

Uma função de ação se chama na 1ª pessoa do presente ("Gravo o arquivo."), e essa forma não pode coincidir com uma palavra que a língua já usa. A 1ª pessoa de "salvar" é "salvo", que já está em "salvo uma falha"; a de "comer" é "como", que faz conversão ("o total como real"). Com uma forma assim a oração teria duas leituras, por isso o verbo não se define: escolha outro.

## Errado

```lavra
Para salvar o arquivo, sendo o arquivo um texto:
    Escrevo "salvo: " seguido do arquivo.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para gravar o arquivo, sendo o arquivo um texto:
    Escrevo "gravado: " seguido do arquivo.

Para começar:
    Gravo "notas.txt".
```
