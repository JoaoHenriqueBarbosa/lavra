# L0215: Operação por extenso com o artigo errado

As operações por extenso são substantivos com gênero fixo, e o artigo concorda com eles: "a soma", "a raiz", "a potência", mas "o produto", "o resto", "o tamanho". Por isso "o raiz" é erro de concordância, como seria em qualquer nome. Troque pelo artigo que concorda.

## Errado

```lavra
Para começar:
    A área é 16,0.
    Escrevo o raiz da área.
```

## Certo

```lavra
Para começar:
    A área é 16,0.
    Escrevo a raiz da área.
```
