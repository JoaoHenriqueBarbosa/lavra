# L0112: "há" numa condição

Na Lavra, a condição vai no futuro do subjuntivo, como no português: "se houver troco", não "se há troco". O modo verbal marca o papel da oração: o presente afirma um fato, e o subjuntivo levanta a hipótese que o "Se" vai conferir. Troque "há" por "houver" (na negação, "Se não houver troco:").

## Errado

```lavra
Para começar:
    O troco, talvez um inteiro, é 5.
    Se há troco:
        Escrevo o troco.
```

## Certo

```lavra
Para começar:
    O troco, talvez um inteiro, é 5.
    Se houver troco:
        Escrevo o troco.
```
