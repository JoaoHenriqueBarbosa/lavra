# L0905: Resto por zero

O resto da divisão por zero, com "módulo" ou com "o resto de", não existe pelo mesmo motivo da divisão: não há quociente. Entre inteiros, a Lavra interrompe o programa em vez de inventar um valor; entre reais, o resultado é indefinido e o programa segue. Um tropeço comum é procurar divisores contando a partir de 0: comece de 1, ou confira o divisor antes.

## Errado

```lavra
Para começar:
    O número é 12.
    Para cada d de 0 até 12:
        Se o número módulo d for igual a 0: escrevo d.
```

## Certo

```lavra
Para começar:
    O número é 12.
    Para cada d de 1 até 12:
        Se o número módulo d for igual a 0: escrevo d.
```
