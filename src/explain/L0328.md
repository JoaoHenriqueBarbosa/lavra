# L0328: Chamada que pode falhar sem tratamento

Uma função declarada com "salvo uma falha" pode desistir em vez de devolver, e quem a chama precisa dizer o que fazer nesse caso, para que nenhuma falha passe calada. Dê um valor de reserva (", ou 0") ou passe a falha adiante (", ou desisto"); passar adiante só vale numa função que também falha ou em "Para começar".

## Errado

```lavra
Para dividir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro, salvo uma falha:
    Se as pessoas forem menores que 1: desisto com "ninguém para dividir".
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de dividir 90 entre 3.
```

## Certo

```lavra
Para dividir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro, salvo uma falha:
    Se as pessoas forem menores que 1: desisto com "ninguém para dividir".
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de dividir 90 entre 3, ou 0.
```
