# L0916: Número que não é código de caractere

Todo caractere tem um código, um número natural, e "como" vai de um para o outro: 'A' como inteiro dá 65, e 65 como caractere dá 'A'. Nem todo número é código de caractere: os negativos, os maiores que 1 114 111 e a faixa reservada de 55 296 a 57 343 não nomeiam caractere nenhum. A Lavra interrompe o programa em vez de escrever um caractere que não existe. Mantenha o número dentro da faixa dos caracteres.

## Errado

```lavra
Para começar:
    O código é 0 menos 1.
    Escrevo o código como caractere.
```

## Certo

```lavra
Para começar:
    O código é 65.
    Escrevo o código como caractere.
```
