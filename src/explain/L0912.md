# L0912: A entrada acabou

Cada leitura com "Leio" consome uma linha da entrada. Se a entrada acaba antes, porque o arquivo redirecionado terminou ou porque quem digitava fechou a entrada (Ctrl+D), não há o que ler, e o programa para. Dê ao programa uma linha para cada leitura: o exemplo errado roda sem entrada nenhuma, e o certo é o mesmo programa com a linha que ele espera.

## Errado

```lavra
Para começar:
    Escrevo "Quantos anos você tem?".
    Leio um inteiro e escrevo "daqui a dez anos: " seguido do resultado mais 10.
```

## Certo

```lavra
Para começar:
    Escrevo "Quantos anos você tem?".
    Leio um inteiro e escrevo "daqui a dez anos: " seguido do resultado mais 10.
```

```entrada
30
```
