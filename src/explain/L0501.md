# L0501: "Senão" que nunca acontece

Quando um "Conforme" trata todos os casos da enumeração, nenhum valor chega ao "Senão", e o código dele nunca roda. É só um aviso, mas apague o "Senão": sem ele, a Lavra confere que o "Conforme" trata todos os casos, e acusa o erro se um caso novo entrar na enumeração e ficar de fora. Com o "Senão" sobrando, esse caso novo cairia nele calado.

## Errado

```lavra
Uma face é uma destas:
    uma cara;
    uma coroa.

Para começar:
    A moeda é uma coroa.
    Conforme a moeda:
        Sendo uma cara: escrevo "ganhei".
        Sendo uma coroa: escrevo "perdi".
        Senão: escrevo "caiu em pé".
```

## Certo

```lavra
Uma face é uma destas:
    uma cara;
    uma coroa.

Para começar:
    A moeda é uma coroa.
    Conforme a moeda:
        Sendo uma cara: escrevo "ganhei".
        Sendo uma coroa: escrevo "perdi".
```
