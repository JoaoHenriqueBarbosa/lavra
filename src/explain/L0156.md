# L0156: Cabeçalho sem verbo no infinitivo

Uma função se define com "Para" e o verbo no infinitivo ("Para render o saldo"), como numa instrução em português, e se executa na 1ª pessoa ("Rendo o saldo."). O compilador tira a forma da chamada do infinitivo, por isso um cabeçalho com o verbo já conjugado, ou com um substantivo no lugar dele, não define função nenhuma. Escreva o infinitivo logo depois de "Para", ou depois do sujeito, num predicado ("Para o saldo exceder o teto").

## Errado

```lavra
Para rendo o saldo, sendo o saldo um real confiado:
    O saldo cresce o saldo vezes 0,05.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para render o saldo, sendo o saldo um real confiado:
    O saldo cresce o saldo vezes 0,05.

Para começar:
    O saldo começa em 100,0.
    Rendo o saldo.
    Escrevo o saldo.
```
