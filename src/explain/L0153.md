# L0153: 1ª pessoa igual a verbo da língua

A 1ª pessoa de um verbo definido no programa não pode ser a de um verbo da própria língua, porque é por ela que a oração escolhe o que executar. "Polir" se conjuga "pulo", que é o "Pulo" dos laços (passa para a próxima volta): "Pulo a peça." ficaria entre chamar a função e pular a volta. Escolha outro verbo, como "lustrar".

## Errado

```lavra
Para polir a peça, sendo a peça um texto:
    Escrevo "polida: " seguido da peça.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para lustrar a peça, sendo a peça um texto:
    Escrevo "lustrada: " seguido da peça.

Para começar:
    Lustro "o anel".
```
