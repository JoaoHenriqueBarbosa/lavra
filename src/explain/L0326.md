# L0326: "Devolvo" sem valor em função que devolve

Uma função com ", devolvendo um ..." promete um valor em toda saída, inclusive nas que acontecem antes do fim. Um "Devolvo." sem valor deixaria quem chama sem o valor prometido, e a Lavra não tem valor nulo para pôr no lugar. Diga qual valor sai ali; se nenhum valor faz sentido, declare a função com "salvo uma falha" e use "desisto com ...".

## Errado

```lavra
Para repartir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro:
    Se as pessoas forem menores que 1: devolvo.
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de repartir 90 entre 3.
```

## Certo

```lavra
Para repartir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro:
    Se as pessoas forem menores que 1: devolvo 0.
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de repartir 90 entre 3.
```
