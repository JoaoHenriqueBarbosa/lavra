# L0373: O mesmo verbo com formas que não combinam

O mesmo verbo, com a mesma regência, pode ser definido para vários tipos: "Para medir a conta, ..." e "Para medir o texto, ...". É o mesmo verbo para outro tipo, e por isso só o tipo do parâmetro muda: as definições devolvem o mesmo tipo, concordam no "salvo engano" e recebem do mesmo jeito (emprestado, confiado ou com posse). Assim, quem chama por um tipo qualquer ("que se mede") sabe o que recebe de volta sem saber qual definição vai rodar. Uma função genérica não divide o verbo com outra, porque já vale para todo tipo. Acerte a definição que destoa, ou dê a ela outro verbo.

## Errado

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um real:
    Devolvo (o tamanho do texto) como real.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
```

## Certo

```lavra
Uma conta é um registro de:
    o saldo, um inteiro.

Para medir a conta, sendo a conta emprestada, devolvendo um inteiro:
    Devolvo o saldo da conta.

Para medir o texto, sendo o texto emprestado, devolvendo um inteiro:
    Devolvo o tamanho do texto.

Para começar:
    A poupança é uma conta com o saldo 7.
    Escrevo o resultado de medir a poupança.
    Escrevo o resultado de medir "lavra".
```
