# L0337: Campo de valor que não é registro

Um caminho como "o saldo da carteira" lê um campo de um registro, e só registro tem campos. O "de" se lê da direita para a esquerda: "o saldo do titular da carteira" pede o saldo do titular, e o titular é um texto, que não tem campo nenhum. Confira o caminho e tire o passo que sobra: o saldo é campo da própria carteira.

## Errado

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo o saldo do titular da carteira.
```

## Certo

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo o saldo da carteira.
```
