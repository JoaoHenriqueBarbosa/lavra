# L0205: Campo com nome de operação da língua

Algumas palavras são operações por extenso da língua: "a soma", "a diferença", "o produto", "o quociente", "o resto", "a potência", "a raiz", "o tamanho", "o módulo", entre outras, além de "o item", das posições. "O produto do pedido" ficaria entre ler um campo e começar uma conta ("o produto de 3 e 4"), por isso essas palavras não servem de nome de campo. Escolha outro nome, como "a mercadoria".

## Errado

```lavra
Um pedido é um registro de:
    o produto, um texto;
    a quantidade, um inteiro.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Um pedido é um registro de:
    a mercadoria, um texto;
    a quantidade, um inteiro.

Para começar:
    A encomenda é um pedido com a mercadoria "café" e a quantidade 2.
    Escrevo a mercadoria da encomenda.
```
