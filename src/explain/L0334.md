# L0334: Nome não declarado

Todo nome precisa ser declarado antes do uso, com "é" (valor fixo) ou "começa em" (valor que muda), e a declaração já traz o valor: assim nada se lê antes de ter valor. O nome também deixa de existir quando acaba o bloco em que foi declarado. Se o nome existe com outra grafia, a dica sugere o mais parecido; senão, declare-o antes da primeira oração que o usa.

## Errado

```lavra
Para começar:
    Escrevo o saldo.
    O saldo é 10.
```

## Certo

```lavra
Para começar:
    O saldo é 10.
    Escrevo o saldo.
```
