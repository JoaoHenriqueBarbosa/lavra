# L0349: Tamanho de quem não é lista nem texto

"o tamanho de" conta os itens de uma lista ou os caracteres de um texto, e só esses dois têm tamanho. Um número não tem tamanho: 4521 é uma quantidade, não uma fileira de algarismos. Para contar os algarismos, converta para texto antes, entre parênteses: "o tamanho de (o código como texto)".

## Errado

```lavra
Para começar:
    O código é 4521.
    Escrevo o tamanho do código.
```

## Certo

```lavra
Para começar:
    O código é 4521.
    Escrevo o tamanho de (o código como texto).
```
