# L0220: Caso com o artigo do gênero errado

Cada caso de enumeração tem o gênero que o artigo da definição deu a ele, e é esse artigo que se repete ao construir o valor: "um azul", porque a definição diz "um azul", mesmo que "cor" seja feminino. O artigo da construção concorda com o caso, não com o tipo ("Uma cor é uma destas:"). Troque pelo artigo do caso.

## Errado

```lavra
Uma cor é uma destas:
    um vermelho;
    um verde;
    um azul.

Para começar:
    O fundo é uma azul.
    Escrevo o fundo.
```

## Certo

```lavra
Uma cor é uma destas:
    um vermelho;
    um verde;
    um azul.

Para começar:
    O fundo é um azul.
    Escrevo o fundo.
```
