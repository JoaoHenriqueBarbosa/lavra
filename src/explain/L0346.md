# L0346: Chamada sem valor usada como valor

"o resultado de cumprimentar" pede o valor que a função devolve, e uma função sem "devolvendo" no cabeçalho não devolve valor nenhum. Uma função assim é uma ação: chame-a como oração, na 1ª pessoa (`Cumprimento "Ana".`). Se ela deve produzir um valor, acrescente "devolvendo um ..." ao cabeçalho e entregue o valor com "Devolvo".

## Errado

```lavra
Para cumprimentar o nome, sendo o nome um texto:
    Escrevo "Olá, " seguido do nome seguido de "!".

Para começar:
    Escrevo o resultado de cumprimentar "Ana".
```

## Certo

```lavra
Para cumprimentar o nome, sendo o nome um texto:
    Escrevo "Olá, " seguido do nome seguido de "!".

Para começar:
    Cumprimento "Ana".
```
