# L0174: Biblioteca que não existe

As bibliotecas vêm com a língua, e cada uma tem um nome: por enquanto, há a de textos ("dividir", "juntar", "conter" e "aparar"). O nome pedido em "Uso a biblioteca de ..." tem de ser o de uma delas, escrito igual.

## Errado

```lavra
Uso a biblioteca de texto.

Para começar:
    Escrevo o resultado de aparar "  lavra  ".
```

## Certo

```lavra
Uso a biblioteca de textos.

Para começar:
    Escrevo o resultado de aparar "  lavra  ".
```
