# L0404: Vista emprestada entregue

O item de um "Para cada", o valor de dentro de um "Se houver" e os campos de um caso no "Conforme" não são donos de nada: são vistas emprestadas do valor de fora, que continua dono da coleção, do "talvez" ou da enumeração. Entregar uma vista (guardá-la numa lista, passá-la a um parâmetro sem particípio, declarar outro nome com ela) tiraria o valor do dono sem ele saber. Entregue uma cópia ("uma cópia da palavra"), e o valor de fora fica como estava.

## Errado

```lavra
Para começar:
    As palavras são "sol", "montanha" e "rio".
    As longas começam vazias.
    Para cada palavra das palavras:
        Se o tamanho da palavra for maior que 3: as longas ganham a palavra.
    Escrevo as longas.
```

## Certo

```lavra
Para começar:
    As palavras são "sol", "montanha" e "rio".
```
