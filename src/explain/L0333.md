# L0333: Caso de outra enumeração

Cada nome de caso pertence a uma enumeração só, e um valor só pode ser um dos casos do próprio tipo. Perguntar se um pedido é "um aprovado", que é caso de pagamento, daria sempre falso; a Lavra acusa a pergunta em vez de aceitar uma condição que nunca acontece. Use um caso da enumeração do valor: a dica lista todos.

## Errado

```lavra
Um pedido é um destes:
    um aberto;
    um pago.

Um pagamento é um destes:
    um pendente;
    um aprovado.

Para começar:
    O pedido é um pago.
    Se o pedido for um aprovado: escrevo "pode enviar".
```

## Certo

```lavra
Um pedido é um destes:
    um aberto;
    um pago.

Um pagamento é um destes:
    um pendente;
    um aprovado.

Para começar:
    O pedido é um pago.
    Se o pedido for um pago: escrevo "pode enviar".
```
