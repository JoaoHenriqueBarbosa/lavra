# L0360: Operação de bits com quem não é inteiro

As operações de bits ("a interseção", "a união", "a disjunção" e "o deslocamento") trabalham sobre os bits de um inteiro, e os bits de um real não têm esse sentido. Deslocar à esquerda não serve de atalho para dobrar um real: multiplique. Se o valor deve mesmo ser tratado bit a bit, declare-o como inteiro, natural ou byte.

## Errado

```lavra
Para começar:
    O peso é 2,5.
    Escrevo o deslocamento do peso por 1 à esquerda.
```

## Certo

```lavra
Para começar:
    O peso é 2,5.
    Escrevo o peso vezes 2.
```
