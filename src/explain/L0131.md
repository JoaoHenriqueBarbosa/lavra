# L0131: Faltou o nome depois do artigo

Na Lavra, o artigo definido marca um nome: "o saldo", "a carteira". Depois dele vem a palavra do nome, sem aspas; entre aspas fica um texto, que é um valor e não leva artigo. Tire as aspas para usar o nome, ou tire o artigo para escrever o texto.

## Errado

```lavra
Para começar:
    O nome é "Ana".
    Escrevo o "nome".
```

## Certo

```lavra
Para começar:
    O nome é "Ana".
    Escrevo o nome.
```
