# L0363: "vazio" para quem não é lista nem texto

"Se as compras forem vazias" pergunta se a lista não tem item nenhum, e "Se o nome for vazio", se o texto não tem caractere nenhum. Um número, um lógico ou um registro não têm tamanho, então a pergunta não faz sentido para eles. Para um número, compare com zero; para um valor que pode faltar, declare com "talvez" e pergunte com "Se houver".

## Errado

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for vazio: escrevo "sem saldo".
```

## Certo

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for igual a 0: escrevo "sem saldo".
```
