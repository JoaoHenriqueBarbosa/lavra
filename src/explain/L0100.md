# L0100: Faltou o ponto final

Todo período da Lavra termina em ponto final, como na escrita. Uma linha que não termina em ponto, dois-pontos ou ponto e vírgula continua na linha de baixo, e é assim que uma oração longa se quebra em várias linhas; quando a linha de baixo já começa outra oração, faltou o ponto na de cima. Ponha o ponto no fim do período.

## Errado

```lavra
Para começar:
    O total é 3
    Escrevo o total.
```

## Certo

```lavra
Para começar:
    O total é 3.
    Escrevo o total.
```
