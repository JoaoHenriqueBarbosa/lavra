# L0163: "Ambos" que não concorda

"Ambos" concorda com os parâmetros a que se refere, como em português: "ambas" quando os dois são femininos ("a receita" e "a despesa"), "ambos" quando pelo menos um é masculino ou é um símbolo ("x"). A concordância é a conferência redundante da Lavra: ela confirma que a palavra fala dos parâmetros que estão no cabeçalho. Troque pela forma que concorda.

## Errado

```lavra
Para a receita superar a despesa, sendo ambos reais, devolvendo um lógico:
    Devolvo o fato de a receita ser maior que a despesa.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Para a receita superar a despesa, sendo ambas reais, devolvendo um lógico:
    Devolvo o fato de a receita ser maior que a despesa.

Para começar:
    A venda é 1200,0.
    Se a venda superar 800,0: escrevo "lucro".
```
