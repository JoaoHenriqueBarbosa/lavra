# L0175: Verbo que já vem de uma biblioteca

Os verbos de uma biblioteca entram no programa que a usa, e a chamada acha a função pelo verbo. Se o programa define um verbo com o mesmo nome (ou com a mesma 1ª pessoa), a oração não diria qual dos dois executa. Dê outro verbo à função do programa; sem a biblioteca, o verbo fica livre.

## Errado

```lavra
Uso a biblioteca de textos.

Para dividir a conta entre as pessoas, sendo a conta um inteiro e as pessoas um inteiro, devolvendo um inteiro:
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de dividir "a,b" por ",".
```

## Certo

```lavra
Uso a biblioteca de textos.

Para repartir a conta entre as pessoas, sendo a conta um inteiro e as pessoas um inteiro, devolvendo um inteiro:
    Devolvo a conta dividido pelas pessoas.

Para começar:
    Escrevo o resultado de dividir "a,b" por ",".
    Escrevo o resultado de repartir 10 entre 2.
```
