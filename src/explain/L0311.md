# L0311: "Conforme" sem todos os casos

"Conforme" sem "Senão" promete tratar todos os casos da enumeração, e o compilador confere a promessa. Assim, um caso esquecido, ou um caso acrescentado à enumeração depois, vira erro de compilação, e não um valor que passa sem ninguém o tratar. Trate cada caso que falta com "Sendo ...:", ou junte o resto num "Senão:".

## Errado

```lavra
Um sinal é um destes:
    um verde;
    um amarelo;
    um vermelho.

Para começar:
    O semáforo é um amarelo.
    Conforme o semáforo:
        Sendo um verde: escrevo "siga".
```

## Certo

```lavra
Um sinal é um destes:
    um verde;
    um amarelo;
    um vermelho.

Para começar:
    O semáforo é um amarelo.
    Conforme o semáforo:
        Sendo um verde: escrevo "siga".
        Senão: escrevo "pare".
```
