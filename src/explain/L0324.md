# L0324: "Paro" ou "Pulo" fora de laço

"Paro" sai do laço em que está, e "Pulo" passa para a volta seguinte; fora de "Repito", "Enquanto" ou "Para cada", não há laço de onde sair nem volta para pular. Para encerrar a função ou o "Para começar" antes do fim, o verbo é "Devolvo".

## Errado

```lavra
Para começar:
    O saldo é 120.
    Se o saldo for maior que 100:
        Escrevo "saldo acima do limite".
        Paro.
    Escrevo "saldo dentro do limite".
```

## Certo

```lavra
Para começar:
    O saldo é 120.
    Se o saldo for maior que 100:
        Escrevo "saldo acima do limite".
        Devolvo.
    Escrevo "saldo dentro do limite".
```
