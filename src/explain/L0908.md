# L0908: Conversão que não cabe

A conversão com "como" confere se o valor cabe no tipo de destino: 300 não cabe num byte, que vai de 0 a 255. Em vez de cortar os bits em silêncio e seguir com outro número, a Lavra interrompe o programa. De real para inteiro, a parte fracionária é descartada, mas a parte inteira ainda precisa caber. Limite o valor à faixa antes de converter, ou converta para um tipo maior.

## Errado

```lavra
Para começar:
    O brilho é 180 mais 120.
    Escrevo o brilho como byte.
```

## Certo

```lavra
Para começar:
    O brilho começa em 180 mais 120.
    Se o brilho for maior que 255: o brilho vira 255.
    Escrevo o brilho como byte.
```
