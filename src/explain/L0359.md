# L0359: Conta com quem não é número

As contas infixas ("mais", "menos", "vezes", "dividido por" e "módulo") só operam números. Um número entre aspas é texto, e texto não vira número sozinho no meio de uma conta. Escreva o número sem aspas; se o valor vem da entrada, leia-o já como número ("Leio um inteiro").

## Errado

```lavra
Para começar:
    O preço é 30.
    O desconto é "5".
    Escrevo o preço menos o desconto.
```

## Certo

```lavra
Para começar:
    O preço é 30.
    O desconto é 5.
    Escrevo o preço menos o desconto.
```
