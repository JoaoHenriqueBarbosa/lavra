# L0211: Posição sem a coleção

"A primeira", "a última" e "o item 2" são posições, e posição é sempre de alguma coleção: "a primeira das notas", "o item 2 da fila". A Lavra não subentende a coleção pelo contexto, como faria uma conversa; sem ela, não há de onde tirar o item. Diga de que coleção é, com o "de" contraído com o artigo dela ("das notas").

## Errado

```lavra
Para começar:
    As notas são 7, 8,5 e 9.
    Escrevo a primeira.
```

## Certo

```lavra
Para começar:
    As notas são 7, 8,5 e 9.
    Escrevo a primeira das notas.
```
