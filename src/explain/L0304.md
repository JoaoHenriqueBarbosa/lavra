# L0304: Tipo ainda não suportado

Este código fica reservado para tipos que a língua ainda não tem: a análise semântica o acusa quando recebe um tipo que sabe nomear, mas ainda não sabe montar. Nenhum programa chega a ele hoje, porque a gramática não produz nenhum tipo assim; se ele aparecer, é defeito do compilador. Os tipos que existem são inteiro, natural, byte, real, lógico, caractere, texto, lista, registro, enumeração e talvez.
