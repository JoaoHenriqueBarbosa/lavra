# L0172: Parâmetro sem tipo

Todo parâmetro precisa de tipo, dado na tipagem depois de "sendo". A única exceção é o objeto com artigo que fica sem tipo: ele vira complemento fixo, parte do nome do verbo ("contar os dias até a data"). Um símbolo, o sujeito de um predicado e os termos regidos por preposição não têm essa leitura, e sem tipo o compilador não sabe que valores eles aceitam: acrescente o tipo que falta.

## Errado

```lavra
Para elevar x a n, sendo x um real, devolvendo um real:
    O produto começa em 1,0.
    Repito n vezes: o produto vira o produto vezes x.
    Devolvo o produto.

Para começar:
    Escrevo o resultado de elevar 2 a 10.
```

## Certo

```lavra
Para elevar x a n, sendo x um real e n um natural, devolvendo um real:
    O produto começa em 1,0.
    Repito n vezes: o produto vira o produto vezes x.
    Devolvo o produto.

Para começar:
    Escrevo o resultado de elevar 2 a 10.
```
