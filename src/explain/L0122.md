# L0122: Verbo desconhecido

Uma oração que não começa por um nome começa por um verbo na 1ª pessoa, e ele tem de ser da língua ("escrevo", "leio", "devolvo", "tomo", "repito", "paro", "pulo", "desisto") ou de uma função do programa. "Imprimo" não é nenhum dos dois. Use o verbo da língua que faz a ação ou, se a ação é do seu programa, defina a função ("Para imprimir ...:").

## Errado

```lavra
Para começar:
    O nome é "Ana".
    Imprimo o nome.
```

## Certo

```lavra
Para começar:
    O nome é "Ana".
    Escrevo o nome.
```
