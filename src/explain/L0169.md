# L0169: Tipo no plural depois de artigo singular

O artigo indefinido e o tipo concordam: depois de "um" ou "uma", o tipo vai no singular ("um real"). Uma coleção não se anota com o tipo dos itens no plural, e sim como lista: "uma lista de reais". O plural do tipo só aparece depois de "lista de" e na tipagem de vários parâmetros de uma vez ("sendo p e q reais").

## Errado

```lavra
Para começar:
    As notas, um reais, são 7, 8,5 e 9.
    Escrevo as notas.
```

## Certo

```lavra
Para começar:
    As notas, uma lista de reais, são 7, 8,5 e 9.
    Escrevo as notas.
```
