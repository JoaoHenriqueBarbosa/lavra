# L0309: "Conforme" sobre valor que não é enumeração

"Conforme" escolhe um bloco para cada caso de uma enumeração, e o compilador confere que nenhum caso ficou de fora; isso só é possível porque uma enumeração tem uma lista fechada de casos. Um texto ou um número pode ter qualquer valor, e não há lista para conferir. Guarde no valor um caso da enumeração ("um verde", não o texto "verde"), ou, para texto e número, use "Se ... for igual a ...:".

## Errado

```lavra
Um sinal é um destes:
    um verde;
    um vermelho.

Para começar:
    O semáforo é "verde".
    Conforme o semáforo:
        Sendo um verde: escrevo "siga".
        Sendo um vermelho: escrevo "pare".
```

## Certo

```lavra
Um sinal é um destes:
    um verde;
    um vermelho.

Para começar:
    O semáforo é um verde.
    Conforme o semáforo:
        Sendo um verde: escrevo "siga".
        Sendo um vermelho: escrevo "pare".
```
