# L0309: "Conforme" sobre valor que não se escolhe por casos

"Conforme" escolhe um bloco para cada caso de uma enumeração, ou para cada valor de um inteiro, de um caractere, de um texto ou de um lógico. Um real não entra: a conta com reais arredonda, e comparar por igualdade exata quase nunca é o que se quer. Lista e registro também não, porque não há casos para listar. Para um real, compare por faixa com "Se ... for menor que ...:"; para lista e registro, examine o tamanho ou um campo.

## Errado

```lavra
Para começar:
    A taxa é 0,5.
    Conforme a taxa:
        Sendo 0,5: escrevo "meia".
        Senão: escrevo "outra".
```

## Certo

```lavra
Para começar:
    A taxa é 0,5.
    Se a taxa for menor que 0,6: escrevo "meia".
    Senão: escrevo "outra".
```
