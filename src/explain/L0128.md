# L0128: Artigo que não concorda com o tipo

O artigo do tipo concorda com o tipo, e não com o nome que ele anota: "a letra, um caractere" (caractere é masculino, mesmo que a letra seja feminina). O gênero é conferido porque um artigo trocado costuma indicar que o tipo não é o que se pensava. Use "um" para os tipos masculinos (inteiro, real, caractere, texto) e "uma" para os femininos (lista, e os registros e enumerações definidos com "Uma").

## Errado

```lavra
Para começar:
    A letra, uma caractere, é 'A'.
    Escrevo a letra.
```

## Certo

```lavra
Para começar:
    A letra, um caractere, é 'A'.
    Escrevo a letra.
```
