# L0212: Ordinal que não concorda com o artigo

O ordinal concorda com o artigo que vem antes dele, em gênero e em número: "a primeira", "o primeiro", "a última". O número é sempre o singular, porque uma posição aponta um item só. Troque o artigo, ou o ordinal, para que os dois concordem.

## Errado

```lavra
Para começar:
    As notas são 7, 8,5 e 9.
    Escrevo o primeira das notas.
```

## Certo

```lavra
Para começar:
    As notas são 7, 8,5 e 9.
    Escrevo a primeira das notas.
```
