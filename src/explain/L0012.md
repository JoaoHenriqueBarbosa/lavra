# L0012: Recuo inconsistente

Na Lavra o recuo é a estrutura: um bloco começa com mais recuo depois dos dois-pontos e termina quando o recuo volta ao de um bloco de fora. Uma linha que volta para um recuo que nenhum bloco aberto tem fica no meio do caminho, e não se sabe a que bloco ela pertence. Alinhe a linha com o começo do bloco a que ela pertence; quatro espaços por nível evitam a dúvida.

## Errado

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for maior que 5:
        Escrevo "alto".
      Escrevo "fim".
```

## Certo

```lavra
Para começar:
    O saldo é 10.
    Se o saldo for maior que 5:
        Escrevo "alto".
    Escrevo "fim".
```
