# L0206: "destas" ou "destes" que não concorda

A enumeração se define com "é uma destas:" ou "é um destes:", concordando com o tipo que se define, e não com os casos: "Uma cor é uma destas:", mesmo que os casos sejam masculinos ("um vermelho"). Cada caso tem o seu gênero, dado pelo próprio artigo; o artigo da definição é o do tipo. Troque pela forma que concorda com o nome do tipo.

## Errado

```lavra
Uma cor é um destes:
    um vermelho;
    um verde;
    um azul.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Uma cor é uma destas:
    um vermelho;
    um verde;
    um azul.

Para começar:
    O fundo é um azul.
    Escrevo o fundo.
```
