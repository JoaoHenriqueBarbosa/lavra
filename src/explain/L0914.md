# L0914: Chamadas demais, uma dentro da outra

Cada chamada ocupa espaço na pilha até terminar, e uma recursão funda demais acaba com ele. A Lavra conta as chamadas abertas e interrompe o programa com mensagem quando passam de 10 000, em vez de deixá-lo cair sem explicação. Se a recursão não tem fim, falta o caso que para; se tem fim, mas é funda demais, troque por um laço.

## Errado

```lavra
Para somar até n, sendo n um inteiro, devolvendo um inteiro:
    Se n for igual a 0: devolvo 0.
    Devolvo n mais o resultado de somar até n menos 1.

Para começar:
    Escrevo o resultado de somar até 20 000.
```

## Certo

```lavra
Para somar até n, sendo n um inteiro, devolvendo um inteiro:
    A soma começa em 0.
    Para cada i de 1 até n: a soma cresce i.
    Devolvo a soma.

Para começar:
    Escrevo o resultado de somar até 20 000.
```
