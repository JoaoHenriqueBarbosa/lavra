# L0300: Programa sem "Para começar"

Um programa da Lavra age em "Para começar:", o bloco que roda quando o programa é executado; o nível de fora só define constantes, funções e tipos, que sozinhos não fazem nada. Sem esse bloco, o programa não tem por onde começar. Acrescente "Para começar:" e, recuado embaixo dele, o que o programa faz.

## Errado

```lavra
A saudação é "Olá, ".

Para saudar o nome, sendo o nome um texto:
    Escrevo a saudação seguido do nome.
```

## Certo

```lavra
A saudação é "Olá, ".

Para saudar o nome, sendo o nome um texto:
    Escrevo a saudação seguido do nome.

Para começar:
    Saúdo "Ana".
```
