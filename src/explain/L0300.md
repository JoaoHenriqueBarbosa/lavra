# L0300: Programa sem "Para começar"

Um programa da Lavra age em "Para começar:", o bloco que roda quando o programa é executado; o nível de fora só define constantes, funções e tipos, que sozinhos não fazem nada. Sem esse bloco, o programa não tem por onde começar. Um arquivo que define funções ou tipos pode ficar sem ele, porque existe para outro arquivo trazer ("Uso o arquivo ..."): a conferência o aceita, e só rodá-lo ou compilá-lo dá este erro. Acrescente "Para começar:" e, recuado embaixo dele, o que o programa faz.

## Errado

```lavra
A saudação é "Olá, ".
```

## Certo

```lavra
A saudação é "Olá, ".

Para começar:
    Escrevo a saudação seguido de "Ana".
```
