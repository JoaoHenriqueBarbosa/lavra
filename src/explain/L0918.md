# L0918: Logaritmo de número que não é positivo

"o logaritmo de x", da biblioteca de matemática, é o logaritmo natural, que só existe para números maiores que zero. De zero ele seria infinito negativo e de um negativo não seria número nenhum; em vez de seguir com um valor assim, a Lavra interrompe o programa, como faz com a raiz de negativo. Confira o número antes de tirar o logaritmo.

## Errado

```lavra
Uso a biblioteca de matemática.

Para começar:
    A medida é 0,0.
    Escrevo o logaritmo da medida.
```

## Certo

```lavra
Uso a biblioteca de matemática.

Para começar:
    A medida é 1,0.
    Se a medida for maior que 0,0: escrevo o logaritmo da medida.
```
