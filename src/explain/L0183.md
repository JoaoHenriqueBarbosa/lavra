# L0183: "invocar" fora da forma

"invocar" chama um verbo que está guardado num nome: primeiro vem o verbo guardado e, depois de "com", os valores que ele recebe, ligados por "e". Serve como oração ("Invoco a ação com o item.") e como valor ("o resultado de invocar a ação com 2 e 3"). O verbo que não recebe nada se invoca sem o "com". Sem o verbo guardado logo depois de "invocar", a frase não diz o que chamar.

## Errado

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para começar:
    A ação é dobrar.
    Invoco com 2.
```

## Certo

```lavra
Para dobrar o número, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o número vezes 2.

Para começar:
    A ação é dobrar.
    Invoco a ação com 2 e escrevo o resultado.
```
