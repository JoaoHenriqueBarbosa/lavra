# L0218: Caso que nenhuma enumeração tem

Em "Conforme", cada "Sendo" pergunta por um caso que alguma enumeração do programa define. Um nome que nenhuma enumeração tem não pode ser tratado: o valor nunca seria esse caso, e o braço nunca rodaria. Acrescente o caso à enumeração, ou corrija o nome.

## Errado

```lavra
Uma forma é uma destas:
    um círculo, com o raio, um real;
    um ponto.

Para começar:
    A figura é um ponto.
    Conforme a figura:
        Sendo um círculo: escrevo "redonda".
        Sendo um quadrado: escrevo "quadrada".
        Sendo um ponto: escrevo "sem área".
```

## Certo

```lavra
Uma forma é uma destas:
    um círculo, com o raio, um real;
    um quadrado, com o lado, um real;
    um ponto.

Para começar:
    A figura é um ponto.
    Conforme a figura:
        Sendo um círculo: escrevo "redonda".
        Sendo um quadrado: escrevo "quadrada".
        Sendo um ponto: escrevo "sem área".
```
