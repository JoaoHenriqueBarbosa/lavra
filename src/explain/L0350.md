# L0350: Operação com tipo errado

Cada operação por extenso de um operando pede o seu tipo: "o negativo" e "o módulo" pedem um número, "a raiz" pede um real, e "o inverso" troca os bits de um inteiro. Não há conversão escondida para o valor caber na operação. Cuidado com "o inverso": ele é o da lógica de bits, não 1 dividido pelo valor; para isso, escreva a divisão.

## Errado

```lavra
Para começar:
    A taxa é 0,25.
    Escrevo o inverso da taxa.
```

## Certo

```lavra
Para começar:
    A taxa é 0,25.
    Escrevo 1,0 dividido pela taxa.
```
