# L0339: Artigo do campo que não concorda

O artigo de um campo concorda com o nome do campo como ele foi declarado no registro, não com o valor guardado nele. O campo é "o titular", então se escreve "o titular da carteira" mesmo quando a conta é da Ana. Use o artigo da definição do registro, como em qualquer nome declarado.

## Errado

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo a titular da carteira.
```

## Certo

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo o titular da carteira.
```
