# L0157: Verbo defectivo sem 1ª pessoa

Uma função de ação se executa na 1ª pessoa do presente ("Meço a carta."). Verbos defectivos, como "abolir", "falir" e "colorir", e os impessoais, como "trovejar", não têm essa forma no português padrão, e o compilador não inventa uma. Escolha outro verbo, ou declare a forma entre parênteses logo depois do infinitivo: é ela que a chamada usa.

## Errado

```lavra
Para trovejar:
    Escrevo "Bruuum!".

Para começar:
    Escrevo "lá vem chuva".
```

## Certo

```lavra
Para trovejar (trovejo):
    Escrevo "Bruuum!".

Para começar:
    Trovejo.
```
