# L0154: Dois verbos com a mesma 1ª pessoa

A chamada acha a função pela 1ª pessoa: "Vendo "gaze"." procura o verbo cuja 1ª pessoa é "vendo". "Vender" e "vendar" se conjugam igual nessa pessoa, então, com os dois no mesmo programa, a oração não diz qual deles executa. Troque um deles por outro verbo; em programas separados, os dois continuam valendo.

## Errado

```lavra
Para vender o produto, sendo o produto um texto:
    Escrevo "vendido: " seguido do produto.

Para vendar a ferida, sendo a ferida um texto:
    Escrevo "coberta: " seguido da ferida.

Para começar:
    Vendo "gaze".
```

## Certo

```lavra
Para vender o produto, sendo o produto um texto:
    Escrevo "vendido: " seguido do produto.

Para enfaixar a ferida, sendo a ferida um texto:
    Escrevo "coberta: " seguido da ferida.

Para começar:
    Vendo "gaze".
    Enfaixo "o joelho".
```
