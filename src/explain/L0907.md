# L0907: Raiz de número negativo

A raiz quadrada de um número negativo não existe entre os reais, e a Lavra interrompe o programa em vez de seguir com um valor indefinido. Confira o sinal antes de tirar a raiz. Na equação do segundo grau, por exemplo, delta negativo quer dizer que não há raízes reais, e é isso que o programa deve dizer.

## Errado

```lavra
Para começar:
    B é 2,0.
    C é 5,0.
    O delta é b vezes b menos 4,0 vezes c.
    Escrevo a raiz do delta.
```

## Certo

```lavra
Para começar:
    B é 2,0.
    C é 5,0.
    O delta é b vezes b menos 4,0 vezes c.
    Se o delta for menor que 0: escrevo "sem raízes reais".
    Senão: escrevo a raiz do delta.
```
