# L0504: Biblioteca trazida duas vezes

Uma biblioteca entra uma vez e vale para o programa inteiro. A segunda frase "Uso a biblioteca de ..." com o mesmo nome não traz nada de novo: apague-a.

## Errado

```lavra
Uso a biblioteca de textos.
Uso a biblioteca de textos.

Para começar:
    Escrevo o resultado de aparar "  lavra  ".
```

## Certo

```lavra
Uso a biblioteca de textos.

Para começar:
    Escrevo o resultado de aparar "  lavra  ".
```
