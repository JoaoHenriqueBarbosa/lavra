# L0011: Número colado numa palavra

Número e palavra são termos diferentes e precisam de espaço entre eles. Um número colado numa palavra, como "3vezes" ou "10kg", não é número nem nome, e a Lavra não adivinha onde um termina e o outro começa. Separe com um espaço; um nome que começa por letra pode ter algarismos depois dela, como o símbolo "x2".

## Errado

```lavra
Para começar:
    Repito 3vezes:
        Escrevo "eco".
```

## Certo

```lavra
Para começar:
    Repito 3 vezes:
        Escrevo "eco".
```
