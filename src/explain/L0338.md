# L0338: Campo que o registro não tem

Um registro só tem os campos da sua definição. Aqui "nome" não é campo da conta, e sim da pessoa guardada no titular dela: o caminho precisa passar pelo titular. Escreva o caminho completo, lido da direita para a esquerda ("o nome do titular da carteira"); a dica lista os campos que o registro tem, e na construção, depois de "com", também só entram esses campos.

## Errado

```lavra
Uma pessoa é um registro de:
    o nome, um texto.

Uma conta é um registro de:
    o titular, uma pessoa;
    o saldo, um real.

Para começar:
    A ana é uma pessoa com o nome "Ana".
    A carteira é uma conta com o titular a ana e o saldo 100,0.
    Escrevo o nome da carteira.
```

## Certo

```lavra
Uma pessoa é um registro de:
    o nome, um texto.

Uma conta é um registro de:
    o titular, uma pessoa;
    o saldo, um real.

Para começar:
    A ana é uma pessoa com o nome "Ana".
    A carteira é uma conta com o titular a ana e o saldo 100,0.
    Escrevo o nome do titular da carteira.
```
