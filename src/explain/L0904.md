# L0904: Divisão por zero

A divisão de inteiros por zero não tem resultado, e a Lavra interrompe o programa com erro em vez de inventar um número. Confira o divisor antes de dividir, como no exemplo certo; numa função, outra saída é declarar "salvo uma falha" e desistir quando o divisor for zero, deixando a decisão para quem chama. Entre reais, a divisão por zero não interrompe o programa: dá infinito.

## Errado

```lavra
Para começar:
    O bolo é 12.
    Para cada n de 3 até 0: escrevo o bolo dividido por n.
```

## Certo

```lavra
Para começar:
    O bolo é 12.
    Para cada n de 3 até 0:
        Se n for igual a 0: escrevo "ninguém para comer".
        Senão: escrevo o bolo dividido por n.
```
