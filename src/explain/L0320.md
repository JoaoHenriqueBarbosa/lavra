# L0320: "perde" ou "Tomo" em quem não é lista

"perde" e "Tomo" tiram um item de uma lista, e só lista tem itens para tirar. Texto não muda letra por letra: para ler uma letra sem tirar nada, use a posição, como "a primeira do nome" ou "a última do nome" (e o nome, que não muda mais, se declara com "é"). Para um número, o verbo de tirar é "diminui".

## Errado

```lavra
Para começar:
    O nome começa em "Ana".
    Tomo a primeira do nome e escrevo o resultado.
```

## Certo

```lavra
Para começar:
    O nome é "Ana".
    Escrevo a primeira do nome.
```
