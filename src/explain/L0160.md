# L0160: Nome tipado que não está no cabeçalho

A tipagem depois de "sendo" dá o tipo dos parâmetros que o cabeçalho acabou de nomear, e só deles. Um nome que não aparece antes, junto do verbo e da regência, não é parâmetro: a chamada não teria onde passar o valor dele. Use na tipagem o mesmo nome do cabeçalho, ou acrescente o parâmetro à regência.

## Errado

```lavra
Para dobrar o valor, sendo o número um inteiro, devolvendo um inteiro:
    Devolvo o valor vezes 2.

Para começar:
    Escrevo o resultado de dobrar 21.
```

## Certo

```lavra
Para dobrar o valor, sendo o valor um inteiro, devolvendo um inteiro:
    Devolvo o valor vezes 2.

Para começar:
    Escrevo o resultado de dobrar 21.
```
