# L0348: "nada" onde não se espera talvez

"nada" é a ausência de um valor "talvez", e só cabe onde o tipo admite faltar. Um texto comum sempre tem valor, e é isso que dispensa conferir ausência antes de cada uso: não existe nulo escondido. Se o valor pode faltar, declare com "talvez" no aposto, e use "Se houver" quando precisar do valor presente.

## Errado

```lavra
Para começar:
    O apelido começa em "Zé".
    O apelido vira nada.
    Escrevo o apelido.
```

## Certo

```lavra
Para começar:
    O apelido, talvez um texto, começa em "Zé".
    O apelido vira nada.
    Escrevo o apelido.
```
