# L0132: Tipo com artigo depois de "como"

A conversão com "como" leva o tipo sem artigo: "o total como real", "42 como texto". Ali o tipo diz o papel que o valor passa a ter, como em "trabalha como professor", e papel não leva artigo; o artigo indefinido fica para o aposto da declaração ("o total, um real, ..."). Tire o artigo.

## Errado

```lavra
Para começar:
    O total é 7.
    Escrevo o total como um real.
```

## Certo

```lavra
Para começar:
    O total é 7.
    Escrevo o total como real.
```
