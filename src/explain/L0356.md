# L0356: ", ou desisto" com motivo

", ou desisto" passa adiante a falha que veio da chamada, com o motivo que ela já tem; não há um segundo motivo para dar. Escreva só ", ou desisto". "Desisto com ...", numa oração própria, é para quando a própria função decide desistir, com um motivo novo.

## Errado

```lavra
Para dividir a conta entre as pessoas, sendo a conta e as pessoas inteiros,
        devolvendo um inteiro, salvo uma falha:
    Se as pessoas forem menores que 1: desisto com "ninguém para dividir".
    Devolvo a conta dividido pelas pessoas.

Para começar:
    A parte é o resultado de dividir 90 entre 3, ou desisto com "conta sem pessoas".
    Escrevo a parte.
```
