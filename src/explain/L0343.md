# L0343: Texto mudado letra por letra

Num texto, a posição dá o caractere só para leitura: as letras ocupam espaços diferentes na memória ("ç" ocupa mais que "c"), e trocar uma delas no lugar poderia mudar o tamanho do texto inteiro. Por isso o texto muda inteiro, com "vira", e o texto novo se monta com "seguido de". Para trocar letras, percorra o texto original e junte as letras do novo.

## Errado

```lavra
Para começar:
    A senha começa em "lavra".
    Para cada i de 1 até o tamanho da senha:
        O item i da senha vira '*'.
    Escrevo a senha.
```

## Certo

```lavra
Para começar:
    A senha é "lavra".
    A máscara começa em "".
    Para cada letra da senha:
        Se a letra for igual a 'a': a máscara vira a máscara seguido de "*".
        Senão: a máscara vira a máscara seguido da letra.
    Escrevo a máscara.
```
