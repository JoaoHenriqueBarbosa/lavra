# L0909: Posição fora da coleção

As posições de uma lista ou de um texto começam em 1 e vão até o tamanho: "o item 1 das notas" é "a primeira das notas", e a última está na posição igual ao tamanho. Ler ou mudar uma posição fora disso interrompe o programa, em vez de mexer na memória vizinha. O tropeço mais comum é contar a partir de 0, como em outras linguagens: percorra de 1 até o tamanho da coleção, ou use "Para cada" direto nela.

## Errado

```lavra
Para começar:
    Os dias são "seg", "ter" e "qua".
    Para cada i de 0 até 2:
        Escrevo o item i dos dias.
```

## Certo

```lavra
Para começar:
    Os dias são "seg", "ter" e "qua".
    Para cada i de 1 até o tamanho dos dias:
        Escrevo o item i dos dias.
```
