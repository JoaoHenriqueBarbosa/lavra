# L0180: Referência declarada com "começa"

"começa em" declara um nome que vai mudar de valor. Uma referência não muda nesse sentido: ela aponta para um lugar do começo ao fim, e o que muda é o valor de lá, por meio dela. Por isso a referência se declara com "é", inclusive a confiada, que serve justamente para mudar: "A favorita é a primeira das contas, confiada." e depois "O saldo da favorita cresce 5.".

## Errado

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    A vista começa nas notas, confiada.
    A vista ganha 10.
    Escrevo a vista.
```

## Certo

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    Se o tamanho das notas for maior que 0:
        A vista é as notas, confiada.
        A vista ganha 10.
    Escrevo as notas.
```
