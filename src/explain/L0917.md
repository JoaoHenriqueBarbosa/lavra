# L0917: Recorte fora do texto

"recortar o texto desde o início até o fim", da biblioteca de textos, devolve os caracteres entre as duas posições, contadas a partir de 1 e as duas incluídas. As posições têm de caber no texto: o início não pode ser menor que 1, o fim não pode passar do tamanho, e o início só pode passar do fim em uma posição, que é o recorte vazio. Fora disso não há trecho para devolver, e a Lavra interrompe o programa. Confira as posições contra "o tamanho" do texto antes de recortar.

## Errado

```lavra
Uso a biblioteca de textos.

Para começar:
    A frase é "lavra".
    Escrevo o resultado de recortar a frase desde 3 até 9.
```

## Certo

```lavra
Uso a biblioteca de textos.

Para começar:
    A frase é "lavra".
    Escrevo o resultado de recortar a frase desde 3 até o tamanho da frase.
```
