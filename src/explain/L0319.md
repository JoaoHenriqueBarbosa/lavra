# L0319: "ganha" em quem não é lista

"ganha" acrescenta um item ao fim de uma lista, e só lista tem itens a acrescentar. Para somar a um número, o verbo é "cresce"; para juntar a um texto, monte o texto novo com "vira ... seguido de ...". Troque o verbo pelo que combina com o tipo do valor.

## Errado

```lavra
Para começar:
    O saldo começa em 100.
    O saldo ganha 50.
    Escrevo o saldo.
```

## Certo

```lavra
Para começar:
    O saldo começa em 100.
    O saldo cresce 50.
    Escrevo o saldo.
```
