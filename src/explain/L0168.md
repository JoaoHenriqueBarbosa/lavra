# L0168: Tipo desconhecido

Todo valor tem tipo conhecido na compilação, e os tipos da língua têm nome fixo: "inteiro", "natural", "real", "byte", "lógico", "caractere", "texto" e "lista de ...", além dos registros e enumerações que o programa define. Não existe um tipo "número" genérico: escolha o que diz o que o valor é, um real para 9,90, um inteiro para uma contagem. Confira também a grafia e o acento ("logico" não é "lógico").

## Errado

```lavra
Para começar:
    O preço, um número, é 9,90.
    Escrevo o preço.
```

## Certo

```lavra
Para começar:
    O preço, um real, é 9,90.
    Escrevo o preço.
```
