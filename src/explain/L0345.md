# L0345: "o resultado" sem oração anterior com valor

"O resultado" retoma o valor que a oração anterior do mesmo período deu: o que "Leio" leu, o que "Tomo" tirou, o que uma função devolveu. O ponto final fecha o período e, com ele, o resultado: a retomada vale dentro da frase, como num texto em português, e nunca aponta para um valor de muitas linhas antes. Junte as orações com "e" no mesmo período.

## Errado

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    Tomo a última das notas.
    Escrevo "tirei " seguido do resultado.
```

## Certo

```lavra
Para começar:
    As notas começam com 7, 8 e 9.
    Tomo a última das notas e escrevo "tirei " seguido do resultado.
```
