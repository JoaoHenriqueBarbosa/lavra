# L0919: Chave que o mapa não tem

"o item "Bia" das idades" lê o valor que o mapa guarda para a chave. Se a chave não está no mapa, não há valor para ler, e a Lavra interrompe o programa em vez de inventar um zero ou um texto vazio. Escrever é diferente: "O item "Bia" das idades vira 25." põe a chave no mapa quando ela não existe. Antes de ler uma chave que pode faltar, pergunte por ela com "Se houver ... em".

## Errado

```lavra
Para começar:
    As idades, um mapa de textos para inteiros, começam vazias.
    O item "Ana" das idades vira 30.
    Escrevo o item "Bia" das idades.
```

## Certo

```lavra
Para começar:
    As idades, um mapa de textos para inteiros, começam vazias.
    O item "Ana" das idades vira 30.
    Se houver "Bia" nas idades: escrevo o item "Bia" das idades.
    Senão: escrevo "sem a idade da Bia".
```
