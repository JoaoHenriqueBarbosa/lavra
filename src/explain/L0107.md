# L0107: Faltou o nome do item em "Para cada"

"Para cada" dá nome a cada item que o laço percorre, e esse nome vem logo depois de "cada": um símbolo ("i") para um intervalo de números, ou um substantivo sem artigo ("nota") para os itens de uma coleção. Sem o nome, o bloco não teria como se referir ao item. Escreva o nome e, num intervalo, "de" antes do começo: "Para cada i de 1 até 3:".

## Errado

```lavra
Para começar:
    Para cada 1 até 3:
        Escrevo "eco".
```

## Certo

```lavra
Para começar:
    Para cada i de 1 até 3:
        Escrevo "eco " seguido de i.
```
