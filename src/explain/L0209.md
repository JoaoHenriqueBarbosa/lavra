# L0209: Caso com nome já usado

O nome de um caso diz sozinho de que enumeração ele é: "A marca é um ponto." constrói o valor sem dizer o tipo. Por isso um caso não pode ter o nome de outro caso, nem de um tipo do programa: aqui, "um ponto" seria ao mesmo tempo o caso da forma e o registro "ponto". Renomeie o caso ou o tipo.

## Errado

```lavra
Um ponto é um registro de:
    x, um real;
    y, um real.

Uma forma é uma destas:
    um círculo, com o raio, um real;
    um ponto.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Uma posição é um registro de:
    x, um real;
    y, um real.

Uma forma é uma destas:
    um círculo, com o raio, um real;
    um ponto.

Para começar:
    A marca é um ponto.
    Escrevo a marca.
```
