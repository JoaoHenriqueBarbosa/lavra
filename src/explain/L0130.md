# L0130: Contração obrigatória

Na Lavra, como no português escrito, preposição seguida de artigo se contrai: "de" com "as" é "das", "em" com "o" é "no", "a" com "o" é "ao", "por" com "a" é "pela". A forma separada ("de as notas") não é aceita, porque a contração é parte da gramática que o compilador confere. A exceção é o sujeito de um infinitivo, em "o fato de o saldo ser ...", que o português também não contrai.

## Errado

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Escrevo o tamanho de as notas.
```

## Certo

```lavra
Para começar:
    As notas são 7, 8 e 9.
    Escrevo o tamanho das notas.
```
