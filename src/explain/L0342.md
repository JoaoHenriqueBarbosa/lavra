# L0342: Mudança de valor fixo

Na Lavra o verbo da declaração diz se o valor muda: "é" declara um valor fixo, e "começa em" promete mudança. Mudar o que foi declarado com "é" (com "vira", "cresce", "ganha" ou outro verbo de mudança) é erro, e a regra vale também para as constantes do nível de fora e para o parâmetro que não chega "confiado". Declare com "começa em" o que vai variar; num parâmetro, peça "confiado" no cabeçalho.

## Errado

```lavra
Para começar:
    O contador é 0.
    Repito 3 vezes: o contador cresce 1.
    Escrevo o contador.
```

## Certo

```lavra
Para começar:
    O contador começa em 0.
    Repito 3 vezes: o contador cresce 1.
    Escrevo o contador.
```
