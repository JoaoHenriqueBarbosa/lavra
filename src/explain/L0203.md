# L0203: "registro" no feminino

"Registro" é masculino, então a definição diz "é um registro de", qualquer que seja o gênero do tipo definido: "Uma conta é um registro de:". O artigo de "uma conta" concorda com "conta"; o de "um registro" concorda com "registro". Troque "uma registro" por "um registro".

## Errado

```lavra
Uma conta é uma registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    Escrevo "pronto".
```

## Certo

```lavra
Uma conta é um registro de:
    o titular, um texto;
    o saldo, um real.

Para começar:
    A carteira é uma conta com o titular "Ana" e o saldo 100,0.
    Escrevo a carteira.
```
