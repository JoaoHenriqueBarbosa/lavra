# L0365: Caso de "Conforme" que não é do tipo do valor

Num "Conforme", os casos são do mesmo tipo do valor que se examina. Sobre uma enumeração, cada caso é um nome dela, com artigo ("Sendo um círculo"); sobre um inteiro, um caractere, um texto ou um lógico, cada caso é um valor desse tipo ("Sendo 1", "Sendo "sim""). Um caso de outro tipo nunca aconteceria. Escreva o caso no tipo do valor.

## Errado

```lavra
Uma forma é uma destas:
    um círculo;
    um ponto.

Para começar:
    A figura é um ponto.
    Conforme a figura:
        Sendo 1: escrevo "círculo".
        Senão: escrevo "ponto".
```

## Certo

```lavra
Uma forma é uma destas:
    um círculo;
    um ponto.

Para começar:
    A figura é um ponto.
    Conforme a figura:
        Sendo um círculo: escrevo "círculo".
        Senão: escrevo "ponto".
```
