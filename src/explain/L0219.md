# L0219: Caso sem artigo indefinido

Um caso de enumeração se diz com artigo indefinido, no gênero que a definição deu a ele: "Sendo um círculo:". O artigo definido marca o nome de um valor ("o raio", "a figura"), então "o círculo" seria uma variável chamada "círculo", e não o caso; "um círculo" diz a espécie do valor, como "um inteiro" diz o tipo. Troque o artigo por "um" ou "uma", conforme o gênero do caso.

## Errado

```lavra
Uma forma é uma destas:
    um círculo, com o raio, um real;
    um ponto.

Para começar:
    A figura é um círculo com o raio 2,0.
    Conforme a figura:
        Sendo o círculo: escrevo o raio.
        Senão: escrevo "sem raio".
```

## Certo

```lavra
Uma forma é uma destas:
    um círculo, com o raio, um real;
    um ponto.

Para começar:
    A figura é um círculo com o raio 2,0.
    Conforme a figura:
        Sendo um círculo: escrevo o raio.
        Senão: escrevo "sem raio".
```
